# 天台十句 · 未寄出的底片

独立的 v2 首章。你最多有十次认真回应的机会，也可以在任何时候收好这一夜。
你观察她愿意让你看到的细节，用自己的话回应；这一夜留下的原句会进入记忆与结尾。

本工程与 `backend/`、`legacy_vue/` 以及运营域名 `tiantaishiju.top` 的进程、存档和部署分离。
开发不会自动推送、合并、连接或重载运营环境。公开目标仅限 `v2.tiantaishiju.top`。

## 本地运行

需要 Node.js 24、Go 1.22+。当前 Codex 环境的官方 Go 位于 `/workspace/.tools/go/bin`；脚本会激活它。

```bash
cd /workspace/tian_tai_shi_ju
bash v2/scripts/build.sh
bash v2/scripts/dev.sh
```

开发前端端口 `5174`，独立后端端口 `8082`。浏览器请求 `/api/v2`，Vite 转发至后端。
退出开发脚本只停止该脚本启动的进程。

```bash
curl -fsS http://127.0.0.1:5174/api/v2/health
cd v2/web
npm run test:e2e
```

## 两种体验

- **现场对话**：配置服务端模型后开放。AI 根据现场、观察物、已发生对白与真实引文生成角色回应；服务端控制十句边界、结局和存档。模型失败不扣句、不生成冒充 AI 的回答。
- **剧本排演**：无密钥可体验完整开场、十句、观察、手记与三个结尾。角色使用作者预写台词；玩家原句仍可存档，但排演不会假装理解自由输入。

模型配置仅保留在服务端，浏览器不保存 API Key：

```text
V2_LLM_BASE_URL=https://api.openai.com/v1
V2_LLM_MODEL=<支持 Chat Completions JSON 对象输出的模型>
V2_LLM_API_KEY=<通过服务器安全配置注入>
V2_LISTEN_ADDR=127.0.0.1:8082
V2_DATA_DIR=<v2 专用的私有存档目录>
```

应用不会读取 v1 的密钥、配置或存档。不要将真实凭据写入仓库。
服务端模型接口细节及限制见 [server/README.md](server/README.md)。

## 体验设计

- 原创雨夜、门内避雨、排演近景与天明空镜，共用角色和空间锚点。即时模式只根据已发生的位置变化切景。
- 摄影机、票据、门灯和雨声成为观察入口，而非数值奖励。
- 角色能否认误解；明确自我介绍后名牌才显示姓名，先前对白仍保留当时的匿名状态。
- AI 可提出有来源的记忆，不能修改剧情计数或凭空制造玩家承诺。
- 手记保留原话，结尾留下可下载的私人纪念页。
- 可以直接收好已经发生的谈话，也可以在十次回应后提出一个告别邀请；她仍可拒绝。提前结束不会补写救助、离场或后来的关系。
- 音乐与雨声由原创 Web Audio 合成，在主动交互后才启动，可单独调节。
- 支持减少动态、大字号、键盘操作、移动端、断线重试和刷新续读。

完整叙事见 [NARRATIVE.md](../docs/v2/NARRATIVE.md)，素材来源见 `art/` 内清单。

用户提供的参考曲可在专用本地入口试听：`node v2/scripts/dev-audio-audition.mjs`，然后打开 `http://127.0.0.1:5178` 的声音设置。需要本机已导入的私有 MP3；普通运行与发布包不包含录音或试听控件。曲目、来源及检查见 [参考配乐说明](../docs/v2/REFERENCE_MUSIC_2026-10-09.md)。

## 验证与部署边界

Go 测试覆盖回合、持久化、并发、模型故障和幂等；前端有状态/设置测试，Playwright 通过真实浏览器运行完整排演。
自动化模拟模型测试不等于真实模型验收。真实模型需配置后逐项验证角色一致性、引用准确性和延迟。

本地也可用[独立模型试玩桥接](server/AGENT_PLAYTEST.md)，让真实 Codex 角色实例按生产提示词即时回应，而玩家通过浏览器游玩；它保留实际引擎与存档校验，但不代表外部供应商 API 已连通。两局完整对话与一局三次回应提前收束的记录见 [真实模型试玩报告](../docs/v2/LIVE_PLAYTEST_2026-10-09.md)。

部署前先阅读 [DEPLOYMENT.md](../docs/v2/DEPLOYMENT.md)。示例配置只属于 v2，不能套用到运营版。
