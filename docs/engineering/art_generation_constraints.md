# 《天台十句》美术资源生成约束

适用范围：`master` 分支正在使用和后续新增的首页、序章、主线状态、情绪、结局、头像及界面素材。视觉基准为用户于 2026-11-04 选定的白底像素首页；人物与叙事以[游戏设定集](../product/game_setting_bible.md)为准。不同分支的设定不能直接套用到本分支。

## 视觉基准

- 白色或近白色留白搭配黑、灰城市与人物，紫色仅作艾的内染等少量识别色。白底是画面语言，主线时间仍是雨夜 23:47。
- 画面是明确的像素画：人物、建筑、栏杆、雨滴与道具都使用清楚的阶梯状像素轮廓和成组的像素明暗，保持统一像素尺度；不能只给平滑插画叠加颗粒或半色调。
- 氛围是克制、孤独、有生活痕迹的当代中文语境都市独立叙事。保留普通住宅、天台、消防门、旧相机和风雨等具体细节，避免霓虹赛博城市、商业海报感和过度煽情。
- 同一幕中的空间、镜头、人物位置、雨势、服装与相机应连续；表情差分只改变必要的表情或微动作。开场、状态与结局各自遵循已有剧情及画面职责。
- 无文字背景不烘焙标题、菜单、对白、字幕、标志或水印。标题和交互控件由界面呈现，保证可访问、可翻译与可响应式布局。

## 艾的人物一致性

- 以已确认的首页及游戏原角色图作为双重参考：艾是 20 岁出头的成年人，深色齐颈短发、自然刘海、低调的紫色内染；神态疲惫、克制、有边界。
- 保持原有深色连帽衫、宽松深色外套和旧相机的识别特征。不同镜头可改变必要的姿态和视角，但不能擅自改成长发、盘发、马尾，或换成不属于原设定的服装。
- 艾不是恋爱攻略奖励，也不是被展示的痛苦符号。避免幼态化、性感化、魅惑姿态，以及把危机或死亡画得唯美。

每张图附上：①用户确认的首页基准 `legacy_vue/art-source/pixel_city_20261104/home-approved.png`；②原角色图 `legacy_vue/public/assets/images/unified_image2_2026-07-31/game_cg/state/avatar_guarded_480.webp` 或已验证的新角色原图；③所需镜头的原有画面（如有）。按以下模板替换方括号：

使用清晰的阶梯状像素轮廓和像素色块，人物与环境保持同一像素尺度。

表情和动作克制，保持镜头之间的角色、服装、相机和天台连续。

盘发或长发、幼态化、性感化、身体伤害或对危机的浪漫化表现。
