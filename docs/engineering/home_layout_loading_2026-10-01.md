# 首页排版与加载调整（2026-10-01）

根据 master 测试站上的页面批注调整。只使用既有黑白灰像素素材，不生成新美术；不修改 shumei、后端、Prompt、规则或存档契约。

## 页面表现

- 标题、短文案、菜单按一条中轴对齐，调整字号、间距与菜单对比度。
- 背景继续灰度显示；移除整页灰度滤镜，标题单独使用低饱和灰紫 `#bfb3d0`。使用原标题透明轮廓做 CSS 色彩混合，保留原有明暗、颗粒和像素笔触。
- 四个入口、声音开关和当前存档逻辑保留；不新增面板、说明段落或图片演出。
- 手机保持已有背景，调整裁切位置让人物可见；390×844 检查无横向溢出，四个按钮均在首屏。

## 图片加载诊断与优化

调整前：首页四张 WebP 共约 360 KB，标题 189 KB、背景 115 KB、两张装饰层合计约 56 KB。本轮普通公网实测这些图下载约 76–466 ms；具体时间受网络、缓存和设备影响。

移除标题雾层和菜单光晕的两张独立图片，只保留背景和标题。通过 `scripts/optimize_home_title.mjs` 从已有 `menu_title.png` 导出带透明通道的 WebP，原始文件不覆盖：

- 桌面标题 900px，约 92 KB；手机标题 600px，约 48 KB。
- 桌面首屏图像约 207 KB，手机约 93 KB。
- 首页在 HTML 头部按屏幕预加载对应标题和背景；其他路由不预加载首页图。
- 新文件含内容摘要，保留长期缓存，避免同名素材被旧缓存覆盖。

复现：在 `legacy_vue` 运行 `node scripts/optimize_home_title.mjs`。仅做既有素材尺寸和编码优化，颜色由 CSS 控制。
