# AIC 独立项目变更记录

## 2026-10-29｜AI × 心理健康沟通特化

本次版本将《天台十句》作为独立 AIC 项目维护，重点把人工智能与心理健康沟通学习连接到可执行的 Prompt、结局判定、局后复盘和 UML 架构文档。

### 运行时改动

- 主线角色 Prompt 加入创伤知情原则：安全、边界、选择权、协作和主体性；明确不诊断、不浪漫化危险、不把玩家写成唯一依靠。
- 提示 Prompt 使用 PFA“观察—倾听—连接”和 MI/OARS 的沟通教练框架。
- 结局裁判 Prompt 增加可观察的心理健康沟通证据门槛。
- 局后复盘 Prompt 新增 `psychological_reading`、`support_skills`、`next_step` 和 `safety_boundary`。
- 前端结算页新增“AI × 心理健康沟通复盘”卡片，并兼容缺少新增字段的旧存档结构。
- 安全回访 Prompt 明确它不是治疗，继续保留选择权、现实支持和当下安全边界。

### 架构和文档改动

- README 增加“生成—评价—守门—复盘”的双调用架构说明。
- 新增 PlantUML UML 组件图和时序图。
- README 增加 WHO、SAMHSA 和 Agent 架构参考文献。
- 增加港科大《Evaluation-Driven Intelligence》评估驱动 Agent 架构启发说明，并将其映射到剧情 LLM、裁判 LLM 和规则守门。
- 清理跨项目、跨分支、旧发布线和历史整合表述，使 AIC 文档成为独立项目文档。
- 删除创作起源叙述，保留虚构内容和现实安全边界。

### 验证边界

自动化测试使用本地模拟模型服务，覆盖字段契约、Prompt 约束、状态结算、前端展示和文档链接；真实模型质量、线上部署、成本、延迟和现实危机干预能力纳入项目评估计划。
