# AIC 竞赛版更改说明

## 2026-10-29｜AI × 心理健康赛道特化

本次提交在数媒版 `shumei-merge` 的固定十句话叙事基础上，形成 AIC 竞赛分支 `AIC`，重点把人工智能与心理健康沟通学习连接到可执行的 Prompt、结局判定和局后复盘。

### 运行时改动

- 主线角色 Prompt 加入创伤知情原则：安全、边界、选择权、协作和主体性；明确不诊断、不浪漫化危险、不把玩家写成唯一依靠。
- 提示 Prompt 改为 PFA“观察—倾听—连接”和 MI/OARS 的沟通教练，要求回应具体内容、验证感受、征得同意、协作小步骤和连接现实支持。
- 结局裁判 Prompt 增加可观察的心理健康沟通证据门槛：安全离开需要持续倾听/验证/选择支持/协作行动以及明确离开动作，信任度仍只是游戏变量。
- 局后复盘 Prompt 新增 `psychological_reading`、`support_skills`、`next_step` 和 `safety_boundary`，使用白名单技能 ID，禁止临床诊断和把游戏结局当作现实干预效果。
- 前端结算页新增“AI × 心理健康沟通复盘”卡片，展示沟通观察、技能、下一步与现实安全边界；旧模型和旧存档缺字段时使用本地保守兜底。
- 安全回访 Prompt 明确它不是治疗，继续保留选择权、现实支持和当下安全边界。

### 文档改动

- 用新的 [AIC Prompt 与 AI × 心理健康沟通规范](../engineering/prompts_and_settings.md) 替代旧版 Prompt 文档。
- 更新项目概述、技术文档、游戏设定集、玩家指南、项目状态和 README，统一 AIC 的 AI+心理健康叙事口径。
- 用 [AIC 竞赛分支说明](branch-aic.md) 替代旧数媒分支说明。

### 验证边界

自动化测试使用本地模拟模型服务，只验证字段契约、Prompt 约束、状态结算和前端展示。真实模型多轮质量、线上部署、成本、延迟和现实危机干预能力仍需单独验证。
