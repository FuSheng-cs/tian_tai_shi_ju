# AIC 独立项目说明

## 项目身份

- 项目名：`《天台十句》AIC`
- 项目定位：AI+心理健康沟通赛道的独立叙事游戏
- 当前维护口径：本项目自身的代码、Prompt、资源、测试和文档
- 文档修订：2026-10-29

AIC 是一个独立项目。本文档不依赖其他项目、分支、发布线或历史整合记录；评审和开发应以当前仓库内容为准。

## 项目定位

AIC 将人工智能与心理健康沟通学习放进同一个可玩的交互链路：

1. AI 角色层根据玩家自由语言生成艾的自然回应，保持主体性、边界和不被治愈的叙事事实。
2. AI 裁判层根据玩家本句、角色回应和当前状态，输出结构化的情绪、姿态、信任、压力和结局候选。
3. AI 提示层以创伤知情、心理急救（PFA）和动机式访谈（MI/OARS）生成下一步沟通方向。
4. AI 复盘层返回关键转折、心理沟通观察、支持技能、下一步和安全边界；所有判断都不构成临床诊断。
5. Go/TypeScript 规则层对模型输出进行归一化、结算和结局守门。

## 评审关注点

1. 玩家通过自然语言与艾对话，每局最多发送十句话。
2. 剧情 LLM 与裁判 LLM 逻辑职责分离；角色输出自然对白，裁判输出结构化 JSON。
3. 安全离开必须满足信任度门槛、可观察的持续支持证据和“落泪—抹泪—一起跨过天台门”的叙事行动。
4. 提示能够区分具体倾听、情绪验证、开放问题、选择支持、协作下一步和现实支持连接。
5. 复盘只描述语言行为，不把信任度、哭泣、沉默或拒绝解释成心理疾病或临床风险等级。
6. 现实危险边界明确：出现明确当下伤害风险时，优先确认安全并联系可信任成年人、专业人员或当地紧急服务；游戏不是危机干预工具。

## 提交边界

- `.env`、`.env.local`、API Key 和本地运行缓存不应提交。
- `node_modules/`、`dist/`、Go 缓存和测试产物由 `.gitignore` 排除。
- 任何危机情境展示都必须保持不浪漫化危险、不把玩家设为唯一依靠、不把虚构结局当作现实干预效果。
- 现实模型质量、线上部署、成本、延迟和现实危机干预能力纳入项目评估计划。

## 验证要求

在项目根目录执行：

```text
cd backend && go test ./... && go build ./...
cd legacy_vue && npm test -- --run && npm run lint && npm run build
node scripts/check_docs.mjs
```
