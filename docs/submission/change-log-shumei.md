# 数媒赛版更改说明

## 提交概览

- 日期：2026-09-19
- 目标：整理一份可用于数媒赛展示与评审的青少年心理安全主题版本
- 主线：十句话内与大学生艾对话，尝试陪她走向下一个安全的地方
- 结局：`end_safe_exit` 安全离开、`end_refusal` 拒绝离开
- 重要边界：本作品是虚构叙事游戏，不是心理治疗、危机干预训练或现实处置工具

## 本次版本内容

### 1. 叙事与安全边界

- 将当前正典统一为大学生艾、学业压力、网络欺凌、家庭冲突和孤独等背景。
- 保留“天台、十句话、AI 对话”的核心识别点，将目标改为陪伴角色找到下一个安全的地方。
- 移除死亡结局、坠落动画、冲击音效和运行路径中的抽烟元素。
- 结局不把一次对话描述为治愈；安全离开后仍强调后续支持和现实中的可信任对象/专业支持。

### 2. 对话规则与 AI 契约

- 每局最多 10 句，每句有效发送消耗 1 次机会；信任度范围为 0–15。
- 倾听、尊重边界和回应压力可触发 `trust_delta = 5`；说教、否定和强迫通过 `pressure_delta` 损耗信任，但不额外扣句数。
- 角色模型负责自然对白，裁判模型负责 `emotion`、`ai_state`、信任/压力变化和 `ending_type` 的结构化判断。
- `end_safe_exit` 必须同时满足本轮结算信任度为 15、AI 判定成立，并包含哭泣及与玩家一起离开；只缺少结局判定时保守收束为拒绝离开。
- 前后端共享当前结局与状态契约，并保留旧存档字段的兼容读取；新主题使用独立的安全版存档和成就命名空间。

### 3. 展示与交互

- 新增安全离开三段演出：落泪、抹泪、与玩家走进楼梯间。
- 桌面端和窄屏端分别使用对应 CG 资源；结局对白完成后按顺序播放，可跳过或重看。
- 结算背景停留在一起离开的画面；拒绝离开停留在天台，不跳转到已经下楼的后日谈。
- 保留首页、开场、主线对话、提示、动态状态、三栏位存档、成就和安全离开后的后日谈链路。
- 本地 `/api` 代理、连接测试错误分类和模拟回复链路便于评审环境启动与复核。

### 4. 测试与文档

- 补充/保留前端状态结算、结局门槛、开场演出、存档、路由、API 连接等回归测试。
- 保留后端 Prompt、裁判契约和信任门槛测试；自动化测试使用 Mock，不向真实模型发送请求。
- 更新根 README、文档索引、游戏设定集、Prompt 文档、项目状态和本分支说明，使代码、剧情和安全边界保持一致。
