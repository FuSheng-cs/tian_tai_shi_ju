# 数媒赛版分支说明

## 分支信息

- 分支名：`shumei`
- 用途：数媒赛展示、评审和作品材料归档
- 快照日期：2026-09-19
- 项目：`《天台十句》`

## 分支定位

本分支以当前可运行的青少年心理安全主题版本为准，目标是提供一份能被评审快速理解、启动和复核的作品快照。它包含前端、后端、游戏资源、当前设定、Prompt 约束、测试以及本次提交说明。

本地目录来自 GitHub 源码压缩包，原始副本不含 Git 历史。提交 PR 时，将当前作品快照接入上游 `master` 的提交历史，以便评审完整文件差异；原始本地快照保留在备份分支中。之后的修改应从本分支继续提交，并在更改说明中同步更新行为、契约、文档和验证结果。

## 评审关注点

1. 玩家通过自然语言与艾对话，每局最多发送十句话。
2. 后端使用角色回复与独立 JSON 裁判双调用，前端展示信任、情绪和状态变化。
3. 安全离开必须同时满足信任度满值和 AI 结局判定，不能仅凭分数或哭泣状态自动成功。
4. 安全离开使用“落泪—抹泪—一起离开”的三段 CG；否则收束为“拒绝离开”，不展示死亡或坠落演出。
5. 达成安全离开后才可进入后日谈；存档、成就和结局收集默认保存在浏览器本地。

## 提交边界

- `.env`、`.env.local`、API Key 和本地运行缓存不应提交。
- `node_modules/`、`dist/`、Go 缓存、测试产物等由 `.gitignore` 排除。
- `legacy_vue/public/assets/` 中被当前页面引用的美术、音频和字体属于作品运行资源，应与代码一起评审。
- 旧版设定、候选美术和历史审查资料仅作追溯依据；与当前[游戏设定集](../product/game_setting_bible.md)冲突时，以当前设定集和[Prompt 文档](../engineering/prompts_and_settings.md)为准。

## 后续维护约定

- Prompt、接口字段、结局规则或存档格式发生变化时，同时更新设定集、Prompt 文档和更改说明。
- 任何涉及危机情境的展示改动，都要保持“不浪漫化危险、不把玩家设为唯一依靠、不把虚构结局当作现实干预效果”的安全边界。
- 提交前至少执行前端测试、前端 lint/build、后端测试/build，以及文档链接检查；真实模型验收需单独标注，不能用 Mock 结果替代。
