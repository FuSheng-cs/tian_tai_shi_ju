## 分支定位

AIC 版沿用数媒版的固定十句话 AI 原生叙事基础，把“人工智能与心理健康深度融合”落实为可执行的交互链路：

1. AI 角色层根据玩家自由语言生成艾的自然回应，保持主体性、边界和不被治愈的叙事事实。
2. AI 裁判层使用创伤知情、心理急救（PFA）和动机式访谈（MI/OARS）的可观察行为规则，参与每回合情绪、信任、压力和结局判断。
3. AI 提示层把下一句拆成回应具体内容、验证感受、尊重选择、协作现实支持等沟通方向，不提供万能台词。
4. AI 复盘层返回关键转折、心理沟通观察、技能标注、下一步和现实安全边界；所有判断都不构成临床诊断。

## 评审关注点

1. 玩家通过自然语言与艾对话，每局最多发送十句话。
2. 后端使用角色回复与独立 JSON 裁判双调用，前端展示信任、情绪和姿态变化。
3. 安全离开必须同时满足信任度门槛、可观察的持续支持证据和“落泪—抹泪—一起跨过天台门”的叙事行动；不能仅凭分数或哭泣自动成功。
4. 提示 Prompt 能区分具体倾听、情绪验证、开放问题、选择支持、协作下一步和现实支持连接，也能识别过早建议、说教责备、强迫施压和遗漏安全确认。
5. 复盘 Prompt 只描述语言行为，不把游戏信任度、哭泣、沉默或拒绝解释成心理疾病或临床风险等级。
6. 现实危险边界明确：出现明确当下伤害风险时，优先确认安全并联系可信任成年人、专业人员或当地紧急服务；游戏不是危机干预工具。

## 提交边界

- `.env`、`.env.local`、API Key 和本地运行缓存不应提交。
- `node_modules/`、`dist/`、Go 缓存、测试产物等由 `.gitignore` 排除。
- 当前 Prompt、接口和复盘字段以 [AIC Prompt 与 AI × 心理健康沟通规范](../engineering/prompts_and_settings.md)为准。
- 旧版摄影师、抽烟、动态回合、死亡/消失/相识三结局只作历史追溯，不得混入 AIC 当前功能或评审描述。
- 任何涉及危机情境的展示改动，都要保持“不浪漫化危险、不把玩家设为唯一依靠、不把虚构结局当作现实干预效果”的边界。
