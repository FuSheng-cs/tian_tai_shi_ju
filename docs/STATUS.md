# 项目状态（2026-09-17）

## 当前改版

青少年心理安全主题：大学生艾、天台、十句话、信任度、AI 剧情，以及“安全离开 / 拒绝离开”两个结局。当前正典见 [游戏设定集](product/game_setting_bible.md)，接口见 [Prompt 文档](engineering/prompts_and_settings.md)。

前端移除抽烟机会图标和首页人物叠层，移除死亡演出与音效调用。信任提升不再奖励额外句数，压力不再额外扣句数。最后一句由模型收束；缺失结局时保守返回拒绝离开。

## 验证范围

前后端自动化测试使用 mock，不代表真实模型已验收。前端类型检查、生产构建、ESLint 及后端各包测试已执行。真实模型多轮体验、专属哭泣 CG 和竞赛展示视频仍需后续制作/验证。尚未发布线上或推送 GitHub。

本轮结果：前端 10 个测试文件、84 项测试通过；vue-tsc、ESLint、Vite 生产构建通过；go test ./... 与 go build ./... 通过。浏览器已检查桌面 1280×720 和窄屏 390×844 首页，修复长文案溢出。此本地副本由 GitHub 源码压缩包取得，不含 Git 历史。

## 本地 API 连接修复（2026-09-17）

未设置 `VITE_BACKEND_URL` 时，前端使用相对 `/api` 地址，但 Vite 原先没有代理，导致连接测试返回 404，未到达 Go 服务。已增加本地代理至 `http://127.0.0.1:8080`，并在设置页区分 HTTP 错误、非 JSON 响应、网络错误和服务商错误。

通过前端地址验证 `/api/health` 返回 200 JSON、`/api/chat` 可返回无密钥模拟回复；这仅验证本地链路，不代表用户的真实 API Key 已验证。新增 10 项连接测试回归用例，当前前端 11 个测试文件、94 项测试全部通过，vue-tsc、ESLint 和生产构建通过。
