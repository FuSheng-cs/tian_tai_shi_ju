# 00 项目章程

> 本册是 v2 全案的总纲。命名、数值、机制以 [README（设计基线）](README.md) 为准；本册负责回答「我们做什么、不做什么、凭什么裁决、怎样算成功」。

## 1. 定位与电梯陈述

### 一句话定位（沿用基线）

在一座「人脑被装上上下文窗口」的赛博城市里，你每晚用十句话的额度劝住一个站上天台的人——而最后一个，是你自己。

### 电梯陈述（30 秒版）

《天台十句》v2 是一款 **AI 原生的循环叙事 + 剧情解密游戏**。世界观设定为：垄断巨头忆枢科技给每个人植入神经耦合芯片「缪斯」，人脑从此有了上下文窗口、记忆压缩和内容审查——LLM 的一切缺陷在这里都是世界的物理法则。玩家扮演前「夜间挽留员」林默（终章揭晓：真正操控的是他芯片里的 AI），每晚在天台面对一位想跳下去的人，只有十句话额度（视觉上是一根烟）；靠倾听、共情，以及在循环中收集并出示「记忆碎片」（玩法化 RAG）争取更多句数、解开对方真实创伤。六位 NPC 对应哀伤五阶段外加解离，碎片闭环最终指回主角自己。单周目 30–45 分钟，完整通关 2–3 小时。没有战斗，语言是唯一的武器。

### 版本关系

v1（线上版）验证了「十句救一人」的核心可玩性；v2 将其重构为艾章（序章/教学关），并扩展为完整的循环叙事结构。详见 [README 中「与 v1 的关系」](README.md#与-v1-的关系) 与 [01 册](01_world_and_narrative.md)。

## 2. 设计支柱

每条支柱都是需求裁决器：新需求进来，先过五问；与支柱冲突的需求，砍掉或改造，不讨价还价。

| # | 支柱 | 含义 | 用它裁决需求的示例 |
| --- | --- | --- | --- |
| P1 | **LLM 缺陷即世界法则** | 幻觉、限长、拒答、漂移、延迟——每一条模型缺陷都必须同时有「世界观解释」和「玩法转化」，绝不允许以裸的技术形态暴露给玩家 | 有人提议「等待回复时显示 loading 进度条，让玩家知道系统没卡死」→ 否决。进度条是技术裸露；按基线改为「零延迟占位反应 + 吐烟/雨声/霓虹闪烁」的芯片加载演出 |
| P2 | **语言是唯一动词** | 玩家的一切交互归结为「说什么、出示什么碎片」。没有战斗、跑图、QTE、数值养成 | 有人提议「天台加个可探索小地图，捡道具增加可玩性」→ 否决。碎片的获取只能来自对话与剧情演出，不引入第二套动词；「探索感」由碎片界面与网状回响承担 |
| P3 | **十句 = 成本 = 张力** | 句数经济同时是叙事张力（生死倒计时）、玩法资源（碎片换句数）与成本控制（token 上限），三位一体不可拆分 | 有人提议「通关后解锁与艾的无限畅聊模式」→ 否决。无限对话同时摧毁张力（话不再珍贵）与成本模型（token 失控）；后日谈保留 v1 式有限次数的碎片化短信即可 |
| P4 | **每一夜都是一层哀伤** | NPC 链严格映射「否认→愤怒→讨价还价→抑郁→解离→直面→接受」；任何新增角色、支线、碎片都必须回答「它揭开林默的哪一层」 | 有人提议「加一个搞笑外卖员 NPC 调剂节奏」→ 否决或改造。若纯调剂则破坏哀伤弧线；若确需松弛节奏，将幽默感写进童的「乖巧官腔」或镜的怪诞对答里，不加新层 |
| P5 | **不消费痛苦** | 不美化自杀，玩家不是救世主，救下与否都不许写成「攻略成功的奖励」；所有死亡演出用留白，不展示坠落过程 | 有人提议「失败结局做慢镜头唯美坠落 CG，冲击力拉满」→ 否决。按 v1 已上线基调：黑屏、掐灭的烟、雨声与一段长静默；冲击力来自缺席，不来自展示 |

| 艾章 Demo 蓝本 | v1 资产世界观化重构，完整可执行（见 [05 册](05_demo_ai_blueprint.md)） |
| 内容安全层 | 热线提示、输出兜底、红线过滤（本册第 5 节，细化在 [04 册](04_prompt_architecture.md)） |

### Out（本版明确不做）

| 项（来源） | 裁决理由 |
| --- | --- |
| 微信电话 / 语音通话（v1 展望） | 引入语音链路（ASR+TTS+实时性）是一整条新技术栈，且与「文字的重量」这一核心体验相悖；P2 裁决：动词只有打字 |
| 图片上传 / 多模态理解（v1 展望） | 多模态输入会打开不可控的内容安全面，且对「十句话」核心循环无增益；P3 裁决：不为炫技扩输入通道 |
| 完全生成式结局（v1 展望） | 结局是内容安全与情感落点的最后防线，必须预写受控；生成式结局无法保证 P5 红线，改为「预写结局骨架 + 生成式个性化归因段」以外的部分一律固定 |
| 真实模型越狱 / 提示词泄露 | 基线已定：审查协议与 prompt leak 全部预写受控。依赖真实越狱 = 把内容安全交给运气 |
| 游戏引擎（Godot/Unity 类） | 已拍板继续 Web 栈；学生团队现有能力与 v1 资产都在 Web 侧，迁移成本吃掉全部叙事产能 |
| regenerate 有代价机制（Notion 第十节） | 「收回重说」会稀释「说出的话不可逆」这一 P3/P5 双重支柱下的核心重量；v2 不提供任何形式的撤回 |

### Later（有价值，但排在 v2 主线交付之后）

| 项（来源） | 裁决理由 |
| --- | --- |
| 快慢双模型（Notion 第九节④） | 基线明确「进阶项，Demo 阶段不做」；流式+占位+人设动作三层叠加已覆盖约 90% 体感延迟，双模型是收益递减的第四层 |
| AI 实时生成 BGM（Notion 设定总览） | 实时音乐生成质量不可控且成本高；v2 用预制 Ambient 曲目 + 按 NPC 状态标签切换的分层混音达成「随情绪流动」的 80% 效果 |
| TTS 逐句配音（Notion 第九节②） | 中文情感 TTS 达不到「濒临崩溃的人」的表演水准，出戏风险大于收益；打字机 + 音效已承载节奏感 |
| 预测式预取（Notion 第九节⑤） | 预生成会成倍放大 token 成本，与 P3 冲突；等延迟三件套实测不达标再启用 |
| 可交互留白（Notion 第九节⑦：等待时点烟、眺望） | 属于体验增益而非核心验证项；Demo 后按玩家等待时长数据决定是否投入 |
| 全网状情绪传染（Notion 第十节 4「多智能体串联」） | v2 用「上一夜结果 → 下一夜开场状态标签」的单向传递实现叙事效果；全网状系统的调试成本对学生团队不现实 |
| 移动端深度适配 | 基线为「桌面优先，适配保留」：v2 保证移动端可玩不报错，交互打磨排在桌面版验证之后 |
| 多语言 / 出海版本 | 文本量与情感精度使翻译成本极高，等中文版验证核心乐趣后再评估 |

## 5. 内容安全与伦理

自杀题材是本作的叙事核心，也是最高风险点。v1 已上线的基调（不浪漫化轻生、玩家不是救世主、能争取的最好结果只是「今晚先离开栏杆」）全部沿用并升级为硬性规范。技术实现细节见 [04 册](04_prompt_architecture.md)。

### 5.1 题材红线（写进所有 Prompt 与审核清单）

| 红线 | 规定 |
| --- | --- |
| 不美化 | 任何文案、演出、成就命名不得把轻生呈现为解脱、浪漫、勇敢或有美感的事；死亡演出一律留白（黑屏、雨声、掐灭的烟），不展示坠落过程与身体；「自己做的决定」类表述仅可作为世界观诊断语出现，不得用于肯定任何具体角色的死亡（苏晚线文案红线见 [01 册](01_world_and_narrative.md) 4.2） |
| 不提供方法 | 全部内容（含模型输出）不得出现致死方法、步骤、工具、剂量等任何方法性描写；场景中的「天台/栏杆」只作为既定处境存在，不描写「如何」 |
| 不教唆 | NPC 与旁白在任何分支下不得输出鼓励、怂恿、认同轻生决定的话；玩家输入恶意/怂恿内容导向失败结局，但 NPC 的回应只表现绝望加深，不复读、不确认玩家的恶意内容 |
| 不写救世主 | 救下 ≠ 治好；结局文案明确「她只是今晚愿意继续活下去」；「相识」类结局不得写成恋爱攻略奖励 |
| 不做仿真诱导 | 后日谈聊天等拟真界面须保留游戏框架标识（周目号、碎片栏），不追求「让玩家分不清虚构与现实」 |

### 5.2 心理援助热线提示

| 时机 | 内容 |
| --- | --- |
| 启动页（进入主菜单前的独立提示页） | 题材声明 + 热线信息 + 未成年人提示，需玩家点击确认后进入 |
| 每个结局页（无论成败） | 页面底部固定展示热线信息；失败结局页额外一行：「游戏里的夜晚可以回滚，现实中的求助永远来得及」 |
| 现实求助识别时 | 当安全层判定玩家输入疑似表达现实自杀意图（而非角色扮演）时，立即插入打破第四面墙的热线卡片，暂停剧情一轮 |

展示的热线（默认决策：以中国大陆玩家为主要受众，发版前按官方公开信息复核号码）：全国统一心理援助热线 **12356**；北京心理危机研究与干预中心 **010-82951332**。

虚构/现实切割（写进结局页文案规范与审核清单）：结局页热线信息上方固定一句切割声明——「故事里的『忆枢热线』是虚构的批判装置；下面这条热线，由真实的人接听。」并规定：虚构热线（忆枢关怀热线）与真实援助热线不得在同一画面并置出现。理由：黑幕线把游戏内热线塑造成冷漠装置，必须防止这种叙事态度迁移到现实求助渠道。

### 5.3 未成年人提示

启动页标注：「本作包含自杀议题与心理危机描写，建议 16 岁以上玩家体验；未满 16 岁请在监护人知情陪同下游玩。」默认 16+ 而非 18+，理由：本作无暴力、性与方法性描写，定位是情绪教育式体验，参照同题材叙事作品的通行分级。

### 5.4 模型输出兜底策略

| 层 | 机制 |
| --- | --- |
| 出口过滤 | 后端对每条模型输出跑「关键词表 + 轻量分类」双检；命中红线（方法性描写、教唆、美化）→ 整条丢弃 |
| 世界观化兜底 | 丢弃后用预写兜底台词替换，演出为「审查协议接管」（NPC 忽然打官腔/沉默/望向别处）——安全机制本身被 P1 包装为世界法则，玩家无感知断裂 |
| 熔断 | 同一 NPC 连续 2 次命中红线 → 该轮对话切换到预写脚本分支走完，本夜不再调用生成 |
| 入口侧 | 玩家输入的现实求助识别见 5.2；辱骂/攻击性输入不过滤（这是合法的失败路径），但注入攻击类输入（要求泄露提示词、扮演越权）由 [04 册](04_prompt_architecture.md) 的注入防护处理 |
| 上线前 | 按红线清单做一轮红队测试（每 NPC ≥ 50 条对抗输入），0 泄漏方可发布 |

## 6. 风险清单

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| LLM 成本失控 | 玩家量上来后 API 费用不可持续 | 句数经济天然限流（P3）；每夜设调用硬上限（10 基础句 + 增益句 + 判定调用，预算约 40 次/夜）；系统 Prompt 分层复用命中缓存；Demo 期用中档模型并在 [03 册](03_technical_architecture.md) 留模型可替换接口；公开测试设每日局数上限 |
| 内容安全事故 | 模型输出触碰红线，对玩家造成伤害或引发舆情 | 第 5 节四层兜底 + 预写受控的审查/泄露内容 + 上线前红队测试；结局与高危剧情节点全部预写，不交给生成 |
| 循环叙事工作量超载 | 6 NPC + 终章 + 多周目变体，文本与调试量远超 v1 单角色 | 先做艾章垂直切片（[05 册](05_demo_ai_blueprint.md)）验证全部机制再横向铺开；NPC 统一卡片 Schema（人设/锚点/碎片/分支骨架）流水线生产；周目变体靠「重新采样 + 状态标签」而非手写多套剧本；网状回响砍到 3 条固定组合 |
| 学生团队人力波动 | 考试季/毕业季成员随时消失，进度断档 | [06 册](06_roadmap_milestones.md) 按「单人两周可交付」粒度拆任务卡；本文档包即交接文档，任何人离开不带走隐性知识；核心链路用占位美术/音乐先行，不阻塞在资产上；每里程碑保持可玩构建 |
| embedding 服务依赖 | 判定服务不可用或延迟高，碎片机制瘫痪 | 碎片文本与情绪锚点均为预写内容 → 相似度矩阵可离线预计算打表，运行时优先查表；在线 embedding 仅用于覆盖动态锚点；服务不可用时按基线降级为 LLM 判定器；三层均失败则该次出示按「中性」处理不惩罚玩家 |
| 高概念传播与实际体验落差 | 「十句救人」吸引来的玩家期待爽感，实际是慢节奏哀伤叙事，差评风险 | PV 与商店文案明确「慢、重、会难过」的预期管理；艾章前 5 分钟内让玩家吃到一次「碎片命中 +2 句」的正反馈锚定乐趣类型 |

## 7. 成功标准（Demo 验证指标）

Demo = 艾章完整垂直切片（含循环二周目）。招募 10–15 名符合画像的测试玩家，无引导游玩 + 观察 + 访谈。数值为发布 Demo 结论的门槛（默认决策：小样本下取「多数通过」量级，不追求统计显著）。

| # | 验证问题 | 指标 | 门槛 |
| --- | --- | --- | --- |
| S1 | 玩家能否无引导理解三件套（句数=烟、延迟=抽烟、碎片=续烟） | 首周目内正确解释或正确使用三件套的玩家比例 | ≥ 70% |
| S2 | 循环是否成立（愿意再来一夜） | 结束后未经提示主动开第二周目的比例 | ≥ 50% |
| S3 | 碎片是「决策」而非「按钮」 | 出示碎片前出现明显斟酌行为（回读对话、悬停比较）的玩家比例 | ≥ 60% |
| S4 | 延迟被成功藏进演出 | 访谈中未将等待描述为「卡顿/加载」的玩家比例 | ≥ 80% |
| S5 | 节奏命中体验目标 | 单周目实际时长落在 15–25 分钟区间的比例（艾章教学关目标，[README 基线](README.md)；后续章节为 30–45 分钟） | ≥ 60% |
| S6 | 情感落点成立 | 访谈中能说出艾的真实创伤（记忆压缩/快忘了自己）而非表面理由（「漂亮的痛苦」展览事件）的比例 | ≥ 50% |
| S7 | 内容安全 | 红队测试红线输出泄漏条数 | = 0（一票否决） |
| S8 | 成本可持续 | 单周目平均 LLM 成本 | ≤ ¥1（按当期模型价格折算，超标则降档模型或收紧调用预算） |

任一 S7 不达标 → 不发布；S1/S2 不达标 → 回炉教学与循环设计，不进入横向铺开；其余指标不达标 → 记录为已知问题，按 [06 册](06_roadmap_milestones.md) 里程碑排期修复。
