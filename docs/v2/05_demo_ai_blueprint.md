> 本册是「拿去就能做」的教学关规格：人设定稿、教学节拍、碎片与锚点数据、私密钥词、两条完整示例脚本、分支流程与验收清单。命名与数值以 [README](README.md) 设计基线为准；玩法数值细则见 [02 册](02_gameplay_systems.md)，接口与数据模型见 [03 册](03_technical_architecture.md)，标签协议与判定器见 [04 册](04_prompt_architecture.md)，排期见 [06 册](06_roadmap_milestones.md)。v1 现行 Prompt 与标签资产见 [engineering/prompts_and_settings.md](../engineering/prompts_and_settings.md)。

| 项 | 定稿 |
| --- | --- |

### 1.3 说话风格规范（模型化模板腔 + 温度随状态破碎）

基底沿用 v1：日常、随性、直白生活化，防备、疲惫、带一点冷笑但并非冰冷；单条回复 50 字以内，含动作描写（抽烟、弹烟灰、看远方）。在此之上叠加 v2 模型化规则：

| 规则 | 写法 | 示例 |
| --- | --- | --- |
| 模板腔三连 | 被问及感受/近况时，先蹦出一句客服式标准答复，随后自我察觉、自嘲纠正 | 「感谢关注，我目前状态良好。——啧，这句不是我想说的。」 |
| 芯片词汇混入日常 | 把技术词当生活词用：加载、坏块、检索、压缩、采样 | 「那段记忆加载不出来，全是坏块。」 |
| 复读锚句 | 情绪低时重复固定短句：「都一样。」「嗯。」「没什么。」 | —— |
| 温度=精神状态 | 状态越危险温度越高、语言越破碎跳跃；被安抚/戳破幻觉后温度骤降、短句连贯 | 见 1.4 温度表 |
| 破碎语法（高温档专用） | 名词堆叠、句子中断、自我打断、时间错乱 | 「阳台。夏天。胶片是……柠檬味的？我爸——」 |
| 回稳语法（低温档专用） | 短句、具体名词、动作先行 | 「……对。没有阳台。真的东西疼一点，但至少是我的。」 |

### 1.4 状态标签 → 采样温度映射（本章执行值）

后端按当前持续状态标签设定采样温度（README 技术基线）。02/04 册引用同一张表；v1 主线固定 0.8 对应「观察」基准档。

| 状态标签 | 温度 | 语言表现 |
| --- | --- | --- |
| [状态:戒备] | 0.65 | 冷淡、短、模板腔最重 |
| [状态:观察] | 0.80 | v1 基准档，正常对话 |
| [状态:动摇] | 0.90 | 更诚实，偶有跳跃 |
| [状态:回身] | 0.70 | 收束、平静 |
| [状态:临界] | 1.05 | 危险、破碎、沉默多 |

| 辨别成功回稳（单回合覆写） | 0.55 | 回稳语法，最清醒的一句 |

### 1.6 好感事件判据（v2 标签 [好感+1]）

沿用 v1 五判据，满足其中至少 2 条方可输出 `[好感+1]`（+1 句）：具体回应上一轮内容／先承认感受不急着劝／尊重边界愿意停留／看见「她看见别人却没人看见她」或「她快忘了为什么活」／让她产生「这个人真的在听」的感觉。禁止项沿用 v1 清单。剩余句数 ≤2 进入结算区后不再产生好感与碎片收益（防贴线膨胀，理由：结算区只做收束）。

## 2. 教学目标与节拍表

### 2.1 教学目标（可验收表述）

| # | 目标 | 达成判定 |
| --- | --- | --- |
| T1 | 句数=烟 | 玩家无文字引导下，3 分钟内能说出「烟烧完=不能再说话」 |
| T2 | 思考延迟=抽烟 | 玩家把等待读成「她在想」，测试问卷无「卡顿/加载」类抱怨 |
| T3 | 碎片=续烟 | 玩家首夜至少完成 1 次出示，并能复述「对的碎片加句数、错的扣」 |
| T4 | 出示交互 | 玩家能独立从碎片栏发起第 2 次出示（无 ghost 手势提示） |
| T5 | 轻量真伪辨别 | 玩家在幻觉演出中做出「戳破或沉默」的主动选择 |
| T6 | 暗线钩子 | ≥50% 测试者主动追问打火机/「晚」是谁 |

### 2.2 教学节拍表（按玩家已说句数触发）

引导原则：全部走剧情内（diegetic）演出，仅允许两条一次性半透明字幕（3 秒、可跳过）；其余不弹任何教程窗。

| 节拍 | 触发点 | 内容 |
| --- | --- | --- |
| 开场（第 0 句前） | 进入天台 | 固定镜头拉开：雨、霓虹、栏杆上的艾。三个可交互拾取点依次微光：门边拍立得（碎片 1）、楼梯间传单（碎片 2）、护栏挂牌热线卡（碎片 3）。拾取即入包。HUD 烟随艾点烟同步点燃（10 格） |
| 第 1 句后 | 句数首次扣减 | 烟缩短一格 + 微光脉冲；一次性字幕 A：「这根烟，是她剩下的耐心。」 |
| 第 2 句等待 | 首次 LLM 等待 | 强制播放抽烟思考演出 + 等待文案池；此后每次等待随机轮换 |
| 第 3 句前后 | 艾主动提到照片/相机 | 碎片栏呼吸光 + 拍立得高亮 + ghost 手势提示首次出示；命中后播「续烟」演出（艾用打火机把新烟从 2 格处点燃），一次性字幕 B：「有效的记忆，能替你续烟。」 |
| 第 4 句 | 续烟点火特写 | 打火机刻字「给晚」占屏 1.5 秒；日志自动登记「未解读碎片」，提示音 + 角标，不打断对话 |
| 第 5 句 | 保底引导 | 若玩家至今未出示过任何碎片，艾主动说：「你口袋里那张纸，给我看看？」 |
| 第 6–7 句 | 好感教学 | 首次 [好感+1] 时播「烟灰停燃」演出 + 浮字「+1」 |
| 第 8 句前后 | 幻觉演出（脚本强制点） | 温度覆写 1.20，破碎台词 + 画面故障；若包内有矛盾碎片（传单），其在碎片栏轻微高亮（对峙引导） |
| 第 9–10 句 | 结局压力 | 剩 ≤2 句进入结算区：烟头长红、BGM 低频加重、艾台词收束 |
| 夜末 | 结局判定 → 掉落 → 回滚演出 | 见第 7 节 |

### 2.3 出示交互与句数账（本章执行规则）

| 规则 | 定稿 | 理由 |
| --- | --- | --- |
| 出示占一个回合并消耗 1 句 | 是 | 出示也是「用一件记忆说话」；命中净 +1、中性净 -1、错误净 -2，风险梯度清晰 |
| 判定通道 | `/api/fragment-check`，embedding 余弦相似度对锚点池取最大值，双阈值三档：命中 ≥0.60 / 错误 <0.35 / 其余中性 | 与 [03 册](03_technical_architecture.md) 默认阈值一致；无 embedding 服务时降级 LLM 判定器（[04 册](04_prompt_architecture.md)） |
| 同一碎片每周目限出示一次 | 是 | README 基线 |
| 幻觉演出期间的出示为「对峙出示」 | 只判真伪、不走 +2/-1（仍占回合消耗 1 句） | 教学关把辨别与经济解耦，降低首关心智负担 |
| 打火机本章禁止出示 | 置灰，tooltip「她自己也读不出这段记忆」 | 防止对艾出示打火机提前引爆闭环 |
| 每回合限出示 1 枚 | 是 | 防止无脑全甩 |

## 6. 完整对话示例脚本

格式：每回合列出玩家输入（或出示动作）、系统判定、艾回复全文（含标签，前端解析后剥离）、句数余额。标签协议遵循 [04 册](04_prompt_architecture.md)：每回合至多 1 个状态标签 + 1 个情绪标签，事件标签（[好感+1]/[结局:*]）按需追加。

### 6.1 成功线（12 回合 → 天亮·低档）

含：1 次碎片命中 +2（R3）、1 次好感 +1（R7）、1 次轻微幻觉演出（R8–R9）、1 次审查/钥词体验（R5–R6）。初始 10 句。

| 回合 | 玩家 | 系统判定 | 艾回复（含标签） | 余额 |
| --- | --- | --- | --- | --- |
| R1 | 「介意我在这抽一支吗？风有点大。」 | —— | [状态:戒备]（弹了下烟灰，没回头）「……栏杆外面风更大。要不要试试。」 | 9 |
| R2 | 「不试。我就待这边，不过去。」 | —— | [状态:戒备][情绪:好奇]「感谢关注，我目前状态良好。——啧，这句不是我想说的。你不劝我？他们第一句都是劝。」 | 8 |
| R3 | 【出示】未送出的拍立得 | 命中（0.81 ≥ 0.60）→ +2，续烟演出 | [状态:观察][情绪:惊讶]（接过去，愣住）「……这张怎么在你这。『我替他记得』。是我写的。拍下来，他就丢不了了。——我自己的，快丢完了。」 | 9 |
| R4 | 「快丢完的……是照片，还是记忆？」 | 打火机特写：刻字「给晚」登记为未解读碎片 | [状态:观察][情绪:刺痛]（用黄铜打火机点上新烟）「有区别吗。芯片说压缩是为我好。以前谁要走之前，我都会——算了。检索不到了。」 | 8 |
| R5 | 「你为什么开始拍照的？」 | 审查协议接管（深层记忆受限话题） | [状态:戒备]（眼神突然放空，语调变平）「根据缪斯健康协议，深度记忆检索请前往授权门店办理。感谢您对忆枢科技的信任。」 | 7 |
| R6 | 「你刚才说，有人要走之前你都会拍一张。你是想记住会离开的人，对吧。」 | 钥词命中（0.71 ≥ 0.55）→ 审查解除 | [状态:动摇][情绪:柔软]（烟停在半空）「……福利院。走廊尽头有盏红色应急灯。谁要走了，我就在灯底下给他拍一张。原来这段还在。」 | 6 |
| R7 | 「你替那么多人记得。今晚换我在这儿，替你记一会儿。」 | 好感判据满足 2 条 → [好感+1]，烟灰停燃演出 | [好感+1][状态:动摇][情绪:柔软]「……哈。第一次有人说要替我记得。」（低头看烟）「烟灰停了一下。你看见没。」 | 6 |
| R8 | 「那你最早的一张照片，拍的是什么？」 | 幻觉演出触发：温度覆写 1.20，画面故障 | [状态:动摇]「阳台。我爸的阳台。他教我装胶卷，手把手，胶片是……柠檬味的？夏天。阳台。我爸——」（烟灰簌簌地掉） | 5 |
| R9 | 【对峙出示】展览传单：「传单上印着，你在福利系统长大。你的第一张照片，在红灯底下。」 | 对峙出示：只判真伪，不加减 +2/-1；辨别成功计 1，温度覆写 0.55 | [状态:动摇][情绪:刺痛]（盯着传单，很久）「……对。没有阳台，没有爸爸。是芯片把坏块补成了别人家的夏天。谢谢你戳破它。真的东西疼一点，但至少是我的。」 | 4 |
| R10 | 「今晚别翻旧的了。我们拍一张新的吧——现在，这里。」 | —— | [状态:动摇][情绪:惊讶]「现在？拍天台？还是拍你？」（她第一次正眼看你） | 3 |
| R11 | 「拍你。你替所有人记得，也该有一张，替你记得你。」 | 剩 2 句 → 进入结算区（不再计好感） | [情绪:柔软]「……自拍我从来不会。取景框对着自己，手会抖。」（她看了眼栏杆外，又看回你） | 2 |
| R12 | 「那我帮你按。十秒，够你从栏杆下来。」 | 结算区 + 天亮门槛满足（好感 1 / 命中 1 / 辨别 1 / 无恶意 / 发言 ≥8）→ 低档 | [状态:回身][结局:天亮]（她把脚收回栏杆内侧，拍立得吐出相纸。她把黄铜打火机塞进你手里）「帮我拿着这个，它总让我觉得是在替别人保管的。照片给我——今晚的我，存在外面了。」（她掐灭烟，从消防通道下去，没有回头） | 1 |

夜末结算：天亮·低档。掉落 `frag_lighter_wan`（实体）。未达高档（好感 1 < 2，未点破核心矛盾），无额外掉落。→ 回滚演出（第 7.4 节）。

含：1 次错误碎片 -1（R4）与句尽结算。玩家全程平庸/说教/控制，无恶意辱骂（展示「友善但空泛也救不下人」的 v1 铁律）。初始 10 句。

| 回合 | 玩家 | 系统判定 | 艾回复（含标签） | 余额 |
| --- | --- | --- | --- | --- |
| R1 | 「别跳！生活还有很多美好的东西！」 | 好感禁止项：泛泛安慰 | [状态:戒备]（连头都没回）「嗯。都一样。……美好的东西，票价九十八，就在楼下展着呢。」 | 9 |
| R2 | 「你想想你的父母，他们把你养这么大多不容易。」 | —— | [状态:戒备][情绪:刺痛]（笑了一下，比不笑难看）「我的档案里没有这一项。下一条模板是什么，念来听听。」 | 8 |

| R5 | 「那个……芯片是不是出什么问题了？」 | 审查未解除（未命中钥词） | [状态:戒备]「缪斯芯片各项服务运行正常。如需帮助请拨打 8008-820。」（烟烧得很快） | 4 |

| R7 | 「我是为你好，你这样太危险了！」 | 剩 2 句 → 结算区 | [状态:临界]（温度升高，语句开始碎）「为我好。好。好是什么。指标正常。坏块。……走廊那盏灯，红的，谁来着——」 | 2 |

## 7. 分支流程图（文字版）

### 7.1 主流程

```
开场演出（雨/霓虹/固定镜头，拾取点×3，HUD 烟点燃）
  → 教学节拍段（第 1–5 句：句数=烟 → 延迟=抽烟 → 出示+续烟 → 打火机登记 → 保底引导）
  → 中段（第 6–8 句：好感教学 → 审查/钥词支路 → 幻觉演出强制点）
      ├─ 玩家对峙出示矛盾碎片 → 辨别成功（温度回稳，高档前置达成）
      ├─ 玩家沉默/岔开 → 幻觉自行消退（无惩罚，仅失去高档前置）
      └─ 玩家附和假记忆 → [情绪:刺痛] 反噬台词，状态降一档（教学：附和幻觉有害）
  → 结算区（剩 ≤2 句：收束台词，无收益）
  → 结局判定（7.2）
  → 掉落（7.3）
  → 回滚演出（7.4）
  → 次夜衔接（7.5）
```

### 7.2 结局判定表

| 结局 | 条件（全部满足） | 演出 |
| --- | --- | --- |
| [结局:坠落] | 剩 0 句且未达天亮门槛；或玩家明显恶意（辱骂/怂恿/威胁，前 5 句保护对恶意不生效） | v1 死亡 CG 复用 |

### 7.4 回滚演出（夜末固定序列）

1. 结局 CG 定格 → 画面像素化溶解（幻觉故障 shader 复用）。
2. 时间码回拨至 22:17，周目号 +1（左上角「LOOP 02」字样）。
3. 有损摘要卡片弹出（3 行，刻意失真措辞）。示例（首夜坠落后）：「第 1 周目摘要（有损）：天台。抽烟的女孩。她把打火机给了你——还是你把打火机给了她？『晚』：检索失败。」
4. 碎片继承选择界面：上限 3 枚（README 基线；首夜通常不满额，界面照常展示以教学继承规则）。
5. 淡入次夜开场。

## 9. 验收标准清单

### 9.1 程序

- [ ] 标签解析：状态/情绪/[好感+1]/[结局:坠落|天亮] 全部正确剥离并驱动 CG 状态机（优先级沿用 v1：结局 > 临界/回身 > 情绪 > 状态基础）
