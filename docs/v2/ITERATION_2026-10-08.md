# 未寄出的底片：玩家体验迭代与验收

基线是远端 `v2/unposted-frames` 的 `c5b12f01`（2026-10-08 15:09，上海时间）。本轮保持独立 Vue 客户端、Go 服务和 v2 数据边界，未修改 `backend/` 或 `legacy_vue/`。原本的 `v2/roadmap`、`v2/unposted-frames` 分支已占用 Git 的 `v2/` 命名空间，因此继续在现有 `v2/unposted-frames` 分支开发，没有删除或改名其他分支。

## 玩家能感到的变化

- 看一眼相机、门灯、小票或雨声，会立即留在手记里，不必先消耗一句话。四张新绘景使用同一主视觉作参考，并按需加载。手记区分「你看见」与有来源的对话记录。
- 二十条排演选项得到各自对应的作者对白。问风不会再收到相机防水的回答，也不会把简单关键词匹配包装成 AI。
- 可以主动让这一刻安静一会儿。确认前明确说明计入一次回应，服务端记录为行动而非说出口的话；未发送的草稿保留。
- 十句之后，玩家可选自己实际说过的某一句作为余响，也可以留白。服务端验证来源，不能引用她的台词或沉默动作标签。不再自动拔高第六句。
- 即时模式结尾遵守角色是否同意的实际回应，采用邀请措辞，不自动宣布同行、联系成功、翌日或人物已经离开天台。完整许可/位置状态机仍属后续工作，当前采用保守呈现。
- 手机观察、输入、留存与设置按钮更易读；序章进度和游戏标题补齐辅助技术语义。保留雨夜插画、细字与留白的构图。
- 原创程序化音乐改为稀疏三音短句、长休止、较轻的持续声部和缓慢混音过渡；雨声独立可调。页面隐藏渐弱暂停，返回续播，手动关闭优先。三条 192 秒样带见 `v2/audio/`。

## 修复的可复现问题

1. Windows 保存文件后对目录执行 `Sync()` 返回 Access denied，导致已落盘却向客户端返回 500。现按系统处理目录同步，文件仍先同步后替换。
2. 自由观察与发言共享版本、互斥锁、持久化幂等回执。并发、断线重试和过期页面不会重复扣句或覆盖历史。
3. 沉默已提交但响应丢失，回首页恢复曾误清未发草稿；现在检查动作类型及实际回合推进。
4. 另一页只新增观察时，版本增加但回合未变；重复上一句话的未发草稿曾被误判为成功发送。现在不再据版本与文本相同就清空。
5. 老存档的自动摘句不再标成「你选择的原话」，显示和导出均采用中性来源标题。

## 公网与模型验证边界

本轮只读访问主域名与 v2 域名均得到 200；v2 仍显示旧的「天台十句 v2 最小版」，不是本轮首章。当前已配置的 SSH 入口 `tiantai-new` 连续超时，直接连接和本机已有代理路径均未建立 SSH 会话。未能查看真实 v2 服务目录、代理与端口隔离，所以未上传、重载、重启或切换任何线上服务。

本地 API 报告 `aiConfigured: false`。验收使用真实 Go 后端的排演模式；模型侧测试模拟 HTTP 传输，不证明真实供应商可用性、实时对白质量或延迟。现场模型验收和公网部署必须在 SSH 恢复、确认 v2 独立路径并配置 v2 专用模型之后进行。

发布包生成方式见 [DEPLOYMENT.md](DEPLOYMENT.md)。新服务可继续读取旧记录，但旧服务不能直接读取包含免费观察/沉默的新记录；回滚必须配合 v2 自身数据快照。

美术调用了内置 `image_gen.imagegen`。用户指定 image2.5，工具没有模型选择或回传版本，故版本未核实；四张原图、编码文件、SHA-256 和提示词规格保存在 `v2/art/`。
