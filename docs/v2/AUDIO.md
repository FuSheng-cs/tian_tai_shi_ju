# V2 原创配乐：《没有关严的门》

这首配乐为《天台十句 · 未寄出的底片》原创。2026-10-08 的玩家体验迭代把固定间隔的单音钟琴改成了**三音短句与更长的无旋律留白**，并降低持续低声部的存在感。声音像雨夜照片里未曝光的部分，不催促玩家回答，也不把角色的处境塑造成壮烈的高潮。低声部从没有三度的开放和声开始，听见对方后才出现小三度，最后停在温暖但不强行解决的 D 大九和声。

这是一份**原创程序化作曲与合成素材**：音符、休止、和声、滤波、包络和空间位置均由项目源码定义，没有使用第三方歌曲、录音采样或外部音乐生成模型，也没有声称调用音乐模型。浏览器实时版本与可下载样带共享同一份乐谱数据。

## 乐谱与配器

开场短句为 **F♯4 → C♯4 → B3**。每阶段各有两句变体，保留相同音域和短句节奏，不使用随机音阶。三个音分别在短句开始、2.8 秒和 6.9 秒落下；下一句从本句开始后 34、39、32、43 秒轮流进入。192 秒样带里有 5 个短句，约 **112.5 秒没有旋律音符或其尾音**，但仍保留雨幕和非常轻的和声空气。无鼓点，不用紧迫节拍催促输入。第一次音符在启用后约 4.8 秒出现，先让环境成为空间。

音色由正弦基音、19% 的二次泛音与 5.5% 的三次泛音组成，85 毫秒柔和起音。基音约 9 秒渐弱，上方泛音分别在 4.2 秒、2.1 秒衰减完，让音色随时间变暖，接近被阻尼的琴键触感；它不是实录钢琴采样。三个极轻的早期反射在 139、227、353 毫秒返回，经过 950 Hz 低通，提供小空间的尾韵，没有反馈回路或空旷大厅混响。

低声部使用四个轻微失谐的正弦声部，基准振幅从旧版的 0.055 / 0.027 降为 0.022 / 0.010 / 0.008 / 0.007，缓慢改变强弱，经过低通滤波。琴键声像固定在中央附近，不让每个音在左右耳间摇摆。

| 剧情阶段 | 低声部 | 音乐 / 雨声相对系数 | 雨声低通 | 听觉变化 |
| --- | --- | --- | --- | --- |
| `arrival` | B2、F♯3、B3、C♯4 | 0.80 / 1.00 | 3900 Hz | 开放的 B 九和声，先听见环境 |
| `listening` | B2、F♯3、D4、E4 | 0.65 / 0.92 | 3300 Hz | 出现小三度，配乐收轻，给阅读留空间 |
| `threshold` | D3、A3、C♯4、E4 | 0.82 / 0.78 | 2600 Hz | 和声转向 D，雨幕的高频逐渐退后 |
| `dawn` | D3、A3、C♯4、E4 | 0.88 / 0.62 | 2200 Hz | 保持未解决的和声，不使用胜利式终止 |

阶段变化采用 **9 秒交叉渐变**，不会通过突然改变同一振荡器音高制造滑音，也不会因每轮回应而重启短句。样带在 0、48、96、144 秒演示四阶段；游戏中按服务端剧情节拍变化。这些内部阶段名描述情绪节奏，**不证明角色已同意走到门内，也不表示当晚已天亮**。雨声的变化表现注意力与叙事重心，不能成为未经确认的剧情事实。

雨声由双声道噪声及低频平滑分量生成，经过约 460 Hz 高通和随阶段改变的低通，再以很慢的幅度变化形成连续雨幕。没有雷声、突发撞击或尖锐雨滴，避免打断阅读。它是风格化合成雨幕，不声称为真实环境录音。

## 浏览器接口与行为

`useAmbientAudio()` 返回 `soundEnabled`、`isPlaying`、`musicVolume`、`rainVolume` 四个 ref，以及：

```ts
enable(): Promise<void>
disable(): void
toggle(): Promise<void>
setMusicVolume(value: number): void // 0–1
setRainVolume(value: number): void  // 0–1
setPhase(phase: 'arrival' | 'listening' | 'threshold' | 'dawn'): void
setLocation(location: 'rooftop' | 'threshold'): void
```

`setLocation()` 只接收服务端确认的 `session.scene.location`，缺失时回退 `rooftop`，不从对白猜测位置，也不由同名的音乐阶段触发。确认进入门边避雨后，独立的雨声空间通道在 2.8 秒内从 18 kHz 低通过渡至 1450 Hz，同时衰减至 78%，让高频雨幕退到门外；确认返回天台则恢复。这一通道与 `setPhase()` 的九秒音乐渐变分开，调整剧情阶段或玩家音量不会取消空间渐变，也不会改变玩家保存的音量值。

进入避雨位置不会开启声音、创建额外 AudioContext、改变音乐旋律或解除静音/隐藏页暂停。静音前已确认的位置会在下一次主动开启时正确应用。独立 Chromium 音频组件实测确认：渐变后为 1450 Hz / 0.78，期间改变阶段与音量没有覆盖它；返回天台恢复 18 kHz / 1，已设为 0 的雨声通道保持为 0；手动暂停后再改位置仍为 suspended，始终只有一个 AudioContext，卸载后为 closed。现有样带继续展示四个音乐阶段的天台混音，没有把固定时间点当成角色已移动的事实。

默认音乐音量为 0.4、雨声为 0.28。两者可分别降到 0；只想听雨时将音乐调到 0。所有剧情信息仍由文字与可见状态完整表达，没有依赖声音的操作或线索。

`setPhase()` 与 `setLocation()` 均可在播放前调用，不会因此创建或启动 AudioContext。音频只在显式点击后的 `enable()` / `toggle()` 中首次启动；重载后不会自动播放。音量偏好存入 localStorage，损坏的记录或浏览器拒绝存储时回退到安全默认值，不影响游戏。手动暂停先渐弱约 650 毫秒再挂起；离开当前标签页先渐弱 150 毫秒，再暂停上下文与短句计时，回到页面时只恢复已获用户启用的声音。音频时钟保留停顿，不补播离开时错过的音符。用户在隐藏期间关闭声音后，返回页面也不会自行开启。

重复调用 `enable()` 不会重置短句进度。组件卸载时释放全部节点、定时器与页面可见性监听。不支持 Web Audio 或恢复播放失败时，状态保持关闭，并允许再次手动尝试。

## 重新生成与测量

需要 Node 24+ 和 ffmpeg，无需 API Key 或网络下载。在仓库根目录运行：

```sh
node v2/audio/render-score.mjs
```

可通过环境变量 `AUDIO_FFMPEG` 指定不在 PATH 中的 ffmpeg 可执行文件。脚本使用固定种子的噪声、共用乐谱和确定的阶段时间重新生成三份样带，并更新 `analysis.json`（含短句时间和无旋律总时长）。临时 PCM 写入系统临时目录，完成后只清理本次创建的目录。浏览器使用 Web Audio 滤波器，离线渲染使用双二阶滤波计算与各阶段滤波后的交叉混合，因此乐谱与混音结构一致，波形不承诺逐采样相同。

本次生成结果：

| 样带 | 综合响度 | 真峰值 | RMS | 时长 |
| --- | --- | --- | --- | --- |
| `demo.ogg` | −23.17 LUFS | −8.92 dBTP | −26.14 dBFS | 192.00 秒 |
| `music-only.ogg` | −22.96 LUFS | −8.03 dBTP | −24.85 dBFS | 192.00 秒 |
| `rain-only.ogg` | −23.34 LUFS | −11.68 dBTP | −27.83 dBFS | 192.00 秒 |

三份原始 PCM 均为 **0 个削波样本、0 个非有限值样本**。编码后真峰值也保留充足余量。音频组合函数测试覆盖主动开启、音量保存、播放拒绝后重试、短句留白、隐藏页暂停与返回、隐藏时关闭不自动恢复、纯雨声、确认避雨位置及返回天台、空间渐变与音量/阶段独立，以及节点释放。

本地 Chromium 实测使用真实 Web Audio：48 kHz，204800 个运行时取样均有限且未削波；关闭音乐后雨声仍有信号，两个音量都设为 0 后输出为数字零。独立 production preview 中实际切换标签页，确认 `running → suspended → running`；离开期间音频时钟保持暂停。自动测量证明文件完整、可解码且没有明显电平异常；本轮没有人类主观听评，旋律、音色和阅读舒适度仍应通过耳机与外放试听判断，不把数值通过写成已完成主观试听。
