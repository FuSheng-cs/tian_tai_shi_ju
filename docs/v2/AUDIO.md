# V2 原创配乐：《没有关严的门》

这首配乐为《天台十句 · 未寄出的底片》本次重构原创。它把雨夜中的等待写成一段有留白的八音动机：声音不催促玩家回答，也不把角色的处境塑造成壮烈的戏剧高潮。低声部从没有三度的开放和声开始，听见对方后才出现小三度，最后过渡到温暖但不强行收束的 D 大九和声。

这是一份**原创程序化作曲与合成素材**：音符、休止、和声、滤波、包络和空间位置均由项目源码定义，没有使用第三方歌曲、录音采样或外部音乐生成模型，也没有声称调用音乐模型。浏览器实时版本与可下载样带共享同一份乐谱数据。

OGG 使用 48 kHz、双声道 Vorbis 编码。样带用于独立试听，响度目标为 −23 LUFS；游戏中保留更轻的混音电平，播放器的音乐与雨声音量可以独立调整。它不是循环截取的背景音文件：现场演奏由用户点击启用后开始，音色、旋律与雨声实时合成，持续时间不限。

## 乐谱与配器

主旋律为 **F♯4 → C♯4 → E4 → B3 → B4 → F♯4 → E4 → C♯4**。音符之间保留约 7–13 秒的休止，没有鼓点或固定的推进节拍。第一次音符在启用后约 2.4 秒出现。音色由正弦基音与轻微二次泛音构成，以 65 毫秒柔和起音、约 7.5 秒渐弱表现偏钟琴的触感；它不是实录钢琴采样。

低声部使用四个轻微失谐的正弦声部，缓慢改变强弱，经过低通滤波。声像只在中央附近移动，避免耳机播放时过度摇摆。

| 剧情阶段 | 低声部 | 音乐 / 雨声相对系数 | 听觉变化 |
| --- | --- | --- | --- |
| `arrival` | B2、F♯3、B3、C♯4 | 1.00 / 1.00 | 开放的 B 九和声，雨声仍在近处 |
| `listening` | B2、F♯3、D4、E4 | 0.82 / 0.90 | 出现小三度，整体收轻，给阅读留空间 |
| `threshold` | D3、A3、C♯4、E4 | 0.94 / 0.72 | 和声转向 D，门里的光逐渐进入 |
| `dawn` | D3、A3、C♯4、E4 | 1.04 / 0.50 | 保持和声而减弱雨幕，不使用胜利式终止 |

阶段变化采用 **7 秒交叉渐变**，不会通过突然改变同一振荡器音高制造滑音。样带为方便审听在 0、21、42、63 秒演示四阶段；游戏中阶段由实际剧情进展决定。

雨声由双声道噪声及低频平滑分量生成，经过约 460 Hz 高通和 4300 Hz 低通，再以很慢的幅度变化形成连续雨幕。没有雷声、突发撞击或尖锐雨滴，避免打断阅读。

## 浏览器接口与行为

`useAmbientAudio()` 返回 `soundEnabled`、`isPlaying`、`musicVolume`、`rainVolume` 四个 ref，以及：

```ts
enable(): Promise<void>
disable(): void
toggle(): Promise<void>
setMusicVolume(value: number): void // 0–1
setRainVolume(value: number): void  // 0–1
setPhase(phase: 'arrival' | 'listening' | 'threshold' | 'dawn'): void
```

默认音乐音量为 0.4、雨声为 0.28。`setPhase()` 可以在播放前调用，不会因此创建或启动 AudioContext。音频只在显式点击后的 `enable()` / `toggle()` 中启动；重载后不会自动播放。音量偏好存入 localStorage，损坏的记录或浏览器拒绝存储时回退到安全默认值，不影响游戏。暂停先渐弱约 650 毫秒再挂起音频上下文，组件卸载时释放全部节点和定时器。不支持 Web Audio 或恢复播放失败时，状态保持关闭。

## 重新生成与测量

需要 Node 24+、ffmpeg 和 ffprobe，无需 API Key 或网络下载。在仓库根目录运行：

```sh
node v2/audio/render-score.mjs
```

脚本使用固定种子的噪声、共用乐谱和确定的阶段时间重新生成两份样带，并更新 `analysis.json`。临时 PCM 写入系统临时目录，完成后只清理本次创建的目录。浏览器使用 Web Audio 滤波器，离线渲染使用等价的双二阶滤波计算，因此乐谱与混音结构一致，波形不承诺逐采样相同。

本次生成结果：

| 样带 | 综合响度 | 真峰值 | RMS | 时长 |
| --- | --- | --- | --- | --- |
| `demo.ogg` | −23.46 LUFS | −12.27 dBTP | −25.59 dBFS | 84.00 秒 |
| `music-only.ogg` | −23.27 LUFS | −12.33 dBTP | −25.16 dBFS | 84.00 秒 |

两份原始 PCM 均为 **0 个削波样本、0 个非有限值样本**。编码后真峰值也保留充足余量。自动测量证明文件完整、可解码且没有明显电平异常；旋律、音色和阅读时的舒适度仍属于需要真实试听判断的审美指标。
