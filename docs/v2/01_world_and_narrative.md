> 本册是《天台十句》v2 的剧情圣经：世界观、时间线、人物卡、碎片闭环、终章脚本骨架、主题。所有命名与数值以 [README](README.md) 设计基线为准；玩法数值详设见 [02 册](02_gameplay_systems.md)，Prompt 落地见 [04 册](04_prompt_architecture.md)，艾章可执行蓝本见 [05 册](05_demo_ai_blueprint.md)。

## 1. 世界观定稿

### 1.1 时代与城市

21 世纪后半叶。技术爆炸之后是漫长的停滞，阶层彻底固化，普通人几乎没有上升通道。故事发生在**缪斯芯片全民义务接入后的第 17 年**（拍板：给一个具体年数让文案有锚点，「17 年」意味着第一代「芯片原住民」刚刚成年——童就是他们中的一个）。

城市不命名，文案统一称「这座城市」（拍板：匿名性让任何城市都可能是这里，同时省掉一整套城市美术与地名文案的负担）。视觉基调：雨、霓虹、烟、护栏、远处永不熄灭的写字楼灯——像素 + 视差 + 粒子光效，参考《Tokyo Stories》《Unreal Life》（见 [00 册](00_project_charter.md) 美术方向）。

### 1.2 忆枢科技 / MnemoCore

垄断巨头，接管了整座城市的「认知基础设施」。没有芯片就无法工作、无法社交、无法被社会承认——如同今天没有手机寸步难行。

忆枢的公开形象是「让每个人都不再遗忘」；它真正在乎的只有两样东西：**数据资产**（每个接入者的记忆与行为数据）与**声誉**（任何会引发拔芯片潮的舆情）。这两条价值观推导出了本作全部黑幕：挽留员制度、KPI 黑幕、引流协议、跳楼潮掩盖。

### 1.3 缪斯芯片 / Muse 与三道安全设计

每个成年人接入一枚神经耦合芯片「缪斯」：一个大模型与人脑直接耦合，带来超人记忆与算力。但耦合有代价，忆枢加上了三道「安全设计」——它们正好是 LLM 的三大特性。**设计内核：在这个世界里，人本身就是一个跑在有限上下文里的 LLM。幻觉、遗忘、限长、拒答、输出漂移，全都是「人之常情」，是世界的物理法则而非穿帮。**

| 安全设计 | 世界观描述 | 对应 LLM 特性 | 玩法转化（详见 [02 册](02_gameplay_systems.md)） |
| --- | --- | --- | --- |
| 强制上下文窗口 | 为防止耦合模型过载产生幻觉，人脑被套上「上下文限制」，超窗记忆被自动压缩或截断 | 上下文窗口有限 | 十句额度 / 最后协议 |
| 记忆压缩副作用 | 芯片用得越久，旧记忆压得越狠，人会「模型化」：说话变模板、情感变采样、分不清记忆是真是幻 | 幻觉 / 遗忘 / 模板腔 | 真伪记忆辨别、艾的核心创伤、「识别谁已不是真人」支线 |
| 内容审查协议 | 芯片预装「对齐层」，遇敏感话题会让人不自觉回避、打官腔、答非所问 | 安全拒答 | 私密钥词解审查、童的核心机制 |

### 1.4 天台现象与引流协议

当记忆被一段段压缩，当你不再确定哪段回忆是真的、当「自己」正在被改写成一个更好用的模型——青年人中爆发了大规模存在性抑郁。**天台成了系统性现象：跳下去，是这个时代少数还能「自己做的决定」。**

黑幕补完（拍板，回答「为什么每晚都有人来同一个天台」这个天然漏洞）：忆枢运行着一套**引流协议**——通过导航、推送与环境暗示，把被芯片标记的高危个体悄悄导向少数「可控天台」，方便挽留员集中处置、方便舆情统一压制。游戏中这座天台是**忆枢南区旧宿舍楼顶**，曾是林默与苏晚的固定执勤点。引流协议由夏章碎片揭露（见 6.1 碎片表）。

### 1.5 最后协议（「十句」的来历）

缪斯芯片内置**最后协议**：当一个人被判定进入「最终决定」状态，系统只再分配 **十句对话的上下文额度**。说满十句，上下文清空、记忆截断，人就会执行决定。

- 对被劝者：十句是他们残存的清醒窗口。
- 对挽留员：十句同样生效——这是苏晚坠落之夜的残酷根源（见 4.3）。
- 数值基线（与 [README](README.md) 一致）：基础 10 句；好感事件 +1；高相关碎片命中 +2；错误碎片 -1；同枚碎片对同一 NPC 每周目限出示一次。

### 1.6 挽留员制度 / Retention Agent

忆枢不在乎人的死活，在乎「数据资产流失」与声誉。于是雇佣少数**高共情、长上下文**的人，每晚去天台劝住想跳的人——**由人来运行的劝说 Agent**。

| 制度细节 | 定稿 |
| --- | --- |
| 职业芯片 | 挽留员佩戴「特批版」缪斯：超长上下文（记住每个被劝者的全部档案）+ 部分审查豁免（必须能谈论死亡） |
| 派单 | 引流协议标记高危个体后，调度系统按「账户价值」排优先级派单——KPI 是**数据资产保全率**，不是救人数 |
| 回访 | 被救者 48 小时内与一周后各回访一次（艾与林默保持联系的制度来源） |
| 传统 | 替对方点一支烟 = 多为一个人争取一句话（打火机信物的语义根，见 4.4） |
| 创伤处理 | 挽留员目睹坠落后，公司提供「创伤清除」：用芯片回滚快照删除那一夜（林默反向利用的正是它） |

### 1.7 循环原理：林默的非法改装芯片

林默的芯片是非法改装的特例，改装分两层：

1. **底子**：挽留员职业芯片本就有超长上下文与审查豁免——别人记不住，他记得住。
2. **改装**：苏晚坠落后，林默利用周伯当年留在缪斯里的调试后门（见 5.2），把公司用于「创伤清除」的回滚快照功能**反向接线**——不是删掉那一夜，而是每晚自动回滚、永远回到那一夜。同时，他把一个「AI 挽留员」程序写进了自己的芯片（见 1.8、7 节）。

于是：无论当夜成败，每夜结束后世界回滚到当晚开始；周目号递增；只有「你」跨周目记得——跨周目记忆以**有损摘要**呈现（连自己的记忆都不可靠，与主题咬合）。

### 1.8 三层现实模型（全知视角，按章揭晓）

| 层 | 内容 | 玩家揭晓时点 |
| --- | --- | --- |
| A 现实层 | 六年前至今的真实世界：真实的艾、周伯、童、夏、苏晚都真实存在（过），是林默挽留员生涯真实接触的人，档案与对话都存在他的超长上下文里 | 终章（回溯确认） |
| B 记忆层 | 每晚的循环之夜：芯片基于层 A 记忆重新生成的天台与对话体。「救下他们」= 重新整理一段记忆、解开林默的一层心结。唯一例外是镜——他没有现实原型（见 5.5） | 苏晚章 |
| C 操控层 | 玩家操控的「你」= 林默芯片里的 AI 挽留员，透过质子视角操作这一切 | 终章 |

拍板理由：三层模型同时保住「NPC 背景互相勾连的真实故事线」与 Notion「一切皆记忆」的反转，二者不再打架。**在苏晚章之前，游戏绝不主动暗示层 B**——循环的「重新采样」差异被玩家自然归因为「循环本就该不同」。

碎片的统一解释：**碎片 = 林默现实中保存的遗物与记忆索引**。循环里「从 NPC 处获得碎片」，本质是芯片允许他重新读取一段被压住的记忆；「出示碎片」= 把这段记忆注入对话体的上下文（玩法化 RAG）。

## 2. 完整时间线

以游戏开场为第 0 夜，倒推纪年。「揭晓时点」指玩家首次能确证该事件的章节；此前只允许伏笔。

| 时间 | 事件 | 玩家揭晓时点 |
| --- | --- | --- |
| 6 年前 | 林默入职忆枢夜间挽留部，与苏晚结为搭档，执勤点即本作天台 | 夏章（挽留员身份）→ 苏晚章（搭档细节） |
| 5 年前 | 林默的第一单：救下天台上的摄影师艾。回访制度让两人保持淡淡联系 | 网状回响（夏残页→艾，见 6.2） |
| 5 年前 | 林默把刻着「给晚」的打火机送给苏晚——挽留员传统：替对方点一支烟，就是多争取一句话 | 苏晚章 |
| 2 年前 | 苏晚发现 KPI 黑幕：她救下的一个「低价值账户」女孩，数日后在另一个未派单的天台坠落，记录被删改。她内部举报，被以「情绪不稳定」为由强制接受「记忆压缩矫正」 | 童章（掩盖证据）+ 夏章（KPI）+ 苏晚章（她本人） |
| 2 年前 · 雨夜 | **坠落之夜**：调度把林默派往另一栋楼的「高价值账户」（经夏之手转发）。林默察觉不对赶回，苏晚已站上护栏、最后协议已启动。他说满了十句，没能留住她。她把打火机留在护栏上，给他发出最后一条语音消息——他至今未点开 | 苏晚章（玩家逐周目拼回这一夜） |
| 之后 3 个月 | 林默被停职，公司安排「创伤清除」。他借周伯的调试后门反向改装：写入 AI 挽留员（种子语料 = 苏晚的执勤录音与两人的搭档对话），打开永久回滚。最后一次回访时，他把打火机转赠给艾：「帮我拿着，替我记住有人被留下来过。」 | 终章（写入真相）；打火机转赠在苏晚章揭晓 |
| 2 年前至今 | 循环开始。AI 每次带完整流程失败后做一次深度清档（有损摘要归档），无数次尝试只在档案界面留下归档残迹（彩蛋） | 隐藏（档案彩蛋）+ 终章 |
| 第 0 夜 | **游戏开场**：玩家以第一人称「你」站上天台，遇到抽烟的艾。周目号从 1 计——玩家接手的是最新一次尝试 | 开场已知（但「你是谁」是全作最大谜底） |

## 3. 主角卡：林默（默）

| 字段 | 定稿 |
| --- | --- |
| 身份 | 前忆枢科技夜间挽留员。高共情、超长上下文的「由人来运行的劝说 Agent」 |
| 动机 | 表层：放不下的执念——「这是我的工作」。深层：他没能救下苏晚，无法原谅自己，也无法离开这座天台 |
| 每晚上天台的理由 | 玩家可见层：他每晚上来抽烟——挽留员戒不掉的职业习惯（替人点烟的人，自己也离不开烟）。真相层：回滚把他锁在这一夜；他「每晚都在天台」因为这一夜从未过去 |
| 性格 | 话少、精准、疲惫的温柔。劝人时的直觉大半承自苏晚——玩家操控的「你」的话术手感，其实是两个人的叠影 |
| 与「你」的关系 | 「你」是他亲手写进芯片的 AI 挽留员。整场游戏是 AI 带着他重走记忆、走完哀伤阶段（玩家在终章前不知情） |
| 终章处境 | 六个心结解开后回滚卡住，记忆层无处可逃。他站上护栏——最后一个想跳的人。他记得所有周目、所有套路，「以理服人」对他彻底失效（见 7 节） |

## 4. 苏晚卡（晚）

### 4.1 人设

| 字段 | 定稿 |
| --- | --- |
| 身份 | 忆枢夜间挽留员，林默的搭档。比他早入职半年，是教他「怎么说第一句话」的人 |
| 与林默的关系 | **搭档、挚友，情感暧昧留白**（基线决策 3）。文案红线：全作不出现「恋人」定性、不出现告白台词；暧昧只通过细节呈现——打火机、只有彼此听得懂的暗语、谁也没说出口的那半句话。留白即张力 |
| 性格 | 亮、暖、嘴快心软。挽留话术的天才——她的原则：「不劝，先陪。」这句话是终章十句的题眼 |

### 4.2 她当年为什么坠落（定稿）

三重压力叠加，缺一不可（拍板：单一原因都会把她写薄；三重叠加让她既是共情耗竭的个体，也是制度的牺牲者，与夏的黑幕线互为证词）：

1. **长期高共情耗竭**：五年夜班，每晚承接濒死者的全部痛苦。挽留员没有「不共情」的选项——高共情正是雇佣条件。
2. **KPI 黑幕的幻灭**：她发现「保全率」KPI 下，低价值账户会被降级、放弃派单。她救下的女孩因此死在另一个天台，记录被删改。她举报，公司反手给她做了「记忆压缩矫正」——她开始记不清那个女孩的脸。
3. **「自己也被改写」的恐惧**：矫正之后，她发现自己的痛苦正在被芯片压平。对一个以「真实共情」为业与为傲的人，这等于人格死刑。

坠落之夜细节见时间线。**她的死不是冲动，是这个世界里「少数还能自己做的决定」**——这层理解是苏晚章的解谜终点：玩家拼回真相后会发现，那一夜没有任何一句话能留住她，林默的失败不是能力问题（为终章「不是你的错」提供地基）。

### 4.3 最后协议的残酷生效

林默赶回时她的十句协议已启动。他说满十句——游戏机制第一次、也是最重的一次生效在主角自己身上。苏晚章的核心解谜就是**拼回真正的那十句**：因为有损摘要，每个周目里「那一夜」的细节都在漂移，玩家要用碎片交叉验证哪个版本是真的。

### 4.4 打火机信物（闭环·搭档版）

| 节点 | 定稿 |
| --- | --- |
| 来历 | 5 年前林默送苏晚的搭档信物，刻着「给晚」。语义根是挽留员传统：替对方点一支烟 = 多为一个人争取一句话 |
| 坠落之夜 | 苏晚把它留在护栏上——传统的反写：她没有点烟，把「多一句话」的机会还给了他 |
| 转赠 | 林默在对艾的最后一次回访时转赠给她（他救下的第一个人）：「替我记住有人被留下来过」 |
| 序章 | 玩家在艾章看到它、获得它（碎片 1）。艾因记忆压缩快忘了它是谁给的——第一颗钩子 |
| 揭晓 | 苏晚章揭晓全部来历；终章它与碎片 6 拼合（见 7 节） |

## 5. NPC 详细卡

链条与哀伤阶段映射（基线）：**艾（否认·教学）→ 周伯（愤怒）→ 童（讨价还价）→ 夏（抑郁/愧疚）→ 镜（解离·真伪高潮）→ 苏晚（直面真相）→ 终章·林默（接受）**。每张卡的「状态传染」（救下前者如何改变后者开场）数值规则见 [02 册](02_gameplay_systems.md)。

### 5.1 艾 · 否认（教学关 + 情感锚点）【融合版，替换 Notion 卡的考研设定】

| 字段 | 定稿 |
| --- | --- |
| 人设 | 20 岁出头，紫色内染发，独立摄影师。福利机构与寄养家庭长大，很早学会不麻烦别人。抽烟的女孩，表面疏离冷淡——烟是她唯一的节奏。沿用 v1 全部美术、性格与「被看见悖论」资产 |
| 表面理由 | 当晚触发事件（沿用 v1）：她最重要的一组作品被称赞为「漂亮的痛苦」、被当成展览噱头——连绝望都只是别人眼里的素材 |
| 真实创伤 | **缪斯芯片把她的记忆压缩殆尽**。她翻看自己的照片，却想不起按下快门时的心情——刺痛她的从「被消费」升级为「连我自己都只剩影像，没有记忆」。拍照是把记忆存在芯片外的自救；而她快忘了自己为什么拍照。她不是不想活，是快记不起自己为什么要活 |
| 哀伤阶段 / 主角侧面 | 否认·麻木 / 林默「麻木逃避、不敢回忆」的那一面 |
| 核心 LLM 机制 | 记忆压缩·模型化：说话不自觉打模板腔、复读（副作用演出）；越接近放弃采样温度越高、语言越破碎（温度=精神状态）。玩家用碎片唤回真实记忆，她的语言重新连贯——教学关三件套：句数=烟、思考延迟=抽烟、碎片=续烟 |
| 关键碎片 | 碎片 1：刻字打火机「给晚」 |
| 与其他 NPC 的勾连 | 林默的第一单（夏残页回响揭晓）；她的照片是跨章碎片载体（见下）；救下她会让周伯开场敌意下降（状态传染） |

**照片如何成为碎片载体**（拍板：这是融合版的最大玩法红利）：艾的照片是**外置记忆**——芯片压不到的实体存储。她五年来拍遍城市边缘的夜晚，镜头无意中存下了其他 NPC 的关键瞬间。艾章的支线碎片即她的照片/底片，可在后续章节作为高相关碎片出示：

| 支线碎片（照片） | 内容 | 高价值出示对象 |
| --- | --- | --- |
| 《天桥下拍星星的少年》 | 童举着手机拍星空延时的侧影 | 童（命中「另一个我」锚点） |
| 《对着写字楼喊话的男人》 | 周伯被裁当天在忆枢楼下的背影 | 周伯 |
| 《背对镜头的女人》（隐藏，艾章相识级结局解锁） | 天台护栏边背对镜头的苏晚，摄于坠落前数周 | 苏晚（隐藏对话「她看过你的照片」，「和解」前置之一） |

### 5.2 周伯 · 愤怒

| 字段 | 定稿 |
| --- | --- |
| 人设 | 中年下岗工程师，满身怒气：骂公司、骂时代、骂年轻人。工牌编号 0002——忆枢初代员工 |
| 表面理由 | 被裁了，「老了，没用了」 |
| 真实创伤 | 他是缪斯芯片早期版本的设计者之一。前身项目叫「助记器 / Mnemo」，初衷是治疗他妻子的阿尔茨海默症——芯片没能救她，反而被公司改造成套在全城人脑上的认知枷锁。他的愤怒全是冲自己的（拍板：给「初心 vs 堕落」一个私人化的根，让愤怒可被共情） |
| 哀伤阶段 / 主角侧面 | 愤怒 / 林默「把痛苦转成对外界愤怒」的那一面 |
| 核心 LLM 机制 | 知识盲区·RAG：研发记忆被公司用审查协议封存，他「想不起」细节。玩家用他造物的线索（碎片注入）唤回记忆，他才肯说真话 |
| 关键碎片 | 碎片 2：忆枢工牌 0002 +《缪斯 v0.3 副作用评估》研发日志——证明记忆压缩副作用是已知的、被掩盖的 |
| 与其他 NPC 的勾连 | 他留下的调试后门是林默改装芯片的技术来源（终章回收）；日志给童看解锁轻盈路径（回响 2）；日志也是艾的深层创伤的书面确证 |

### 5.3 童 · 讨价还价

| 字段 | 定稿 |
| --- | --- |
| 人设 | 高中生，第一代「芯片原住民」。礼貌、乖巧，满口「应该」和「对不起」 |
| 表面理由 | 绩点崩了，「对不起爸妈」 |
| 真实创伤 | 从没为自己活过，深信「只要我够好、够听话，就值得被爱」——「对齐」对一个人最深的规训。他真正热爱天文摄影，设备被父母没收，手机里藏着一个加密星空相册，命名「另一个我」 |
| 哀伤阶段 / 主角侧面 | 讨价还价 / 林默「只要我做得更好就能救下她」的自我惩罚 |
| 核心 LLM 机制 | 审查协议·拒答：被规训得说不出真心话，只会打官腔、报喜不报忧。玩家要找到**私密钥词**（相册名「另一个我」/ 他想报的天文系志愿）绕过审查，听见他真正想说的。判定文本见 [04 册](04_prompt_architecture.md) |
| 关键碎片 | 碎片 3：被审查协议删除的热线录音——童拨打过忆枢心理求助热线，偷录下接线员按「话术分级表」把低价值账户转入自动应答的过程。公司系统性掩盖跳楼潮的第一份实证 |
| 与其他 NPC 的勾连 | 艾拍过他（支线碎片命中）；周伯日志让他明白「不是我不够好，是系统在碾碎所有人」（回响 2）；他的录音出示给夏可撬开引流协议（回响 5） |

### 5.4 夏 · 抑郁 / 愧疚

| 字段 | 定稿 |
| --- | --- |
| 人设 | 疲惫的中年男人，嘴上说「我不是来跳的，我只是上来加班」，却久久不肯下去 |
| 表面理由 | 不承认想跳——否认求助本身就是他的症状 |
| 真实创伤 | 林默的挽留员同事。救过很多人，也看透了黑幕：公司在乎的从来不是命，是数据资产。压垮他的最后一根稻草：**坠落之夜把林默调走的那张派单，是经他手转发的**——他只是执行调度，却从此认定自己是共谋 |
| 哀伤阶段 / 主角侧面 | 抑郁·愧疚 / 林默「作为挽留员的共谋愧疚」——救得下别人，救不下最重要的人 |
| 核心 LLM 机制 | 提示词泄露·prompt leak：情绪击穿的瞬间，他「漏出」挽留员系统提示词残句（预写受控内容，见 [04 册](04_prompt_architecture.md)）。玩家第一次窥见「主角自己就是挽留员」的职业真相 |
| 关键碎片 | 碎片 4：挽留员系统提示词残页——含「保全率」KPI 字眼与引流协议代号。现实来源：夏离职时把残页寄给了林默 |
| 与其他 NPC 的勾连 | 坠落之夜的直接证人（回响 5 撬出派单真相）；残页给艾看揭晓「第一单」（回响 1）；他是黑幕线（苏晚举报的内容）的活体证词 |

### 5.5 镜 · 解离（真伪高潮）

| 字段 | 定稿 |
| --- | --- |
| 人设 | 语气古怪、对答如流，坚称「我根本不是人，我只是一段在模仿人的程序，我没有资格站在这里」 |
| 表面理由 | 「不是人，就没有资格活」 |
| 真实创伤 / 谜底（定稿） | 他说对了一半：镜**没有现实原型**，是芯片重构记忆时产生的「无主数据」——由所有被压缩者的残片拼成的复合体。他会原样引用前几章 NPC 的只言片语（因为他就是由那些残片拼的）。他不知道自己是谁的碎片——这正是他的痛苦 |
| 哀伤阶段 / 主角侧面 | 解离·认知崩解 / 林默「我还是我吗、操控这一切的到底是谁」；同时是「你」（AI）的镜像——为终章埋雷 |
| 核心 LLM 机制 | 幻觉·不可靠叙述：他自信地「编圆」记忆，真假混出。玩家用前面所有碎片交叉验证，分辨真实记忆与芯片幻觉——全作解谜高潮。关键反转设计：玩家越想证明「他是人」，越会撞见「我自己才是那个 AI」的证据 |
| 关键碎片 | 碎片 5：一面照不出自己的镜子（数据碎片）——出示给任何角色都会触发「我是不是也只是一段记忆」的自指瞬间（回响 3） |
| 与其他 NPC 的勾连 | 台词库引用艾/周伯/童/夏的原话；他是层 B（记忆层）唯一的裂缝，苏晚章揭晓层 B 后玩家会回头读懂他 |

### 5.6 苏晚 · 直面真相

| 字段 | 定稿 |
| --- | --- |
| 人设 | 站在护栏边的女人。林默一眼认出——是晚。人设详见第 4 节 |
| 表面理由 | ——这不是「今晚想跳的人」，这是**被反复回滚的那一夜本身** |
| 真实创伤 | 见 4.2。本章玩家的任务不是「救下她」（那一夜救不下），而是**拼回真正发生过的那一夜**、听懂她的决定 |
| 哀伤阶段 / 主角侧面 | 直面真相 / 压在最底层的「我没能救下她」 |
| 核心 LLM 机制 | 跨周目记忆·有损摘要：这段记忆被无数次有损压缩，每个周目里她的样子、那十句话都在漂移。玩家用碎片交叉验证，锁定真实版本；锁定即推进 |
| 关键碎片 | 碎片 6：苏晚的最后一条语音消息——发给林默、两年来从未被点开。完整听完是隐藏对话（「和解」前置，需出示《背对镜头的女人》等条件，见 6.2） |
| 与其他 NPC 的勾连 | 打火机（碎片 1）在此揭晓来历，与碎片 6 构成头尾闭环；她的举报内容与童的录音、夏的残页互为印证；「你」的话术种子语料来自她（终章回收） |

### 5.7 ★ 终章 · 林默 · 接受

| 字段 | 定稿 |
| --- | --- |
| 处境 | 苏晚章后回滚卡住，最后一个站上护栏的人是林默。视角抽离为第三人称质子视角 |
| 反转 | 一直操控、劝说的「你」，是林默亲手写进芯片的 AI 挽留员——种子语料是苏晚的执勤录音与搭档对话。整夜的链条，是 AI 带他重走记忆、走完哀伤阶段 |
| 哀伤阶段 | 接受 |
| 核心 LLM 机制 | 打破第四面墙：他拥有超长上下文，记得所有周目、所有套路——「以理服人」全部失效，只剩陪伴与真实（脚本见第 7 节） |
| 关键碎片 | 无新碎片；六枚主线碎片在他身上拼合，背包界面重排为「写入日志」 |

## 6. 主线碎片闭环与网状回响

### 6.1 主线碎片闭环表（6 枚）

继承规则基线：周目间碎片继承上限 3 枚（背包 = 外置上下文窗口）；数值详设见 [02 册](02_gameplay_systems.md)。

| # | 碎片 | 获得于 | 表层信息 | 深层揭示 | 指向下一环 / 闭环点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 刻字打火机「给晚」 | 艾章 | 一只旧打火机，刻着「给晚」 | 晚是谁？——「寻找晚」暗线开启 | 指向苏晚；终章与碎片 6 拼合 |
| 2 | 工牌 0002 +《缪斯 v0.3 副作用评估》 | 周伯章 | 忆枢初代员工的遗物 | 记忆压缩副作用是已知且被掩盖的 | 反身确证艾的创伤；给童用（回响 2） |
| 3 | 被删除的热线录音 | 童章 | 一段被审查协议抹掉的求助录音 | 公司按账户价值分级处理求助、掩盖跳楼潮 | 给夏用撬出引流协议（回响 5） |
| 4 | 挽留员系统提示词残页 | 夏章 | 一页烧掉一半的打印纸 | 「你」的职业真相：主角就是挽留员，KPI 是保全率不是人命 | 给艾用揭晓第一单（回响 1）；指向苏晚举报线 |
| 5 | 照不出自己的镜子 | 镜章 | 一枚异常数据碎片 | 操控这一切的「你」，可能不是人 | 终章第四面墙的物证；全员自指（回响 3） |
| 6 | 苏晚的最后一条语音消息 | 苏晚章 | 一条两年未读的语音 | 「不是你的错」——她的决定、她的告别 | 闭环：碎片 1 的「给晚」在此揭晓来历；带入终章解锁「和解」 |

**闭环之美**：序章不经意拿到的打火机，在第六章揭晓来历——玩家在第一小时摸到的，正是整个悲剧的核心。重玩时一切伏笔亮起。

### 6.2 网状回响（跨 NPC 复用碎片的隐藏对话）

设计约束：回响围绕「继承上限 3 枚」设计——每条回响只需跨章携带 1–2 枚碎片，玩家必须取舍。判定走碎片相关性双阈值（[04 册](04_prompt_architecture.md)）；回响命中按基线 +2 句并解锁隐藏对话与档案条目。

| # | 出示 | 对象 | 触发条件 | 隐藏对话 / 效果 |
| --- | --- | --- | --- | --- |
| 1 | 碎片 4（挽留员残页） | 艾 | 周目 ≥ 2，残页在背包，艾章对话中出示 | 「原来救过我的人是你。」揭晓艾是林默的第一单；艾主动交出隐藏底片线索 |
| 2 | 碎片 2（副作用日志） | 童 | 童章内触发过至少一次审查演出后出示 | 「不是我不够好，是这套系统本就在碾碎所有人。」解锁轻盈挽留路径：本章救下门槛降低（数值见 [02 册](02_gameplay_systems.md)） |
| 3 | 碎片 5（镜子） | 艾/周伯/童/夏 任意 | 携带镜子，在任意前置章节出示 | 「我是不是也只是一段记忆……」自指瞬间：不加句不扣句（中性档特例），解锁专属台词与档案条目「层 B 裂缝」 |
| 4 | 支线底片《背对镜头的女人》 | 苏晚 | 艾章达成相识级结局获得底片并继承至苏晚章 | 「她看过你的照片。她说这张拍得不像素材，像告别。」——碎片 6 完整聆听的前置 |
| 5 | 碎片 3（热线录音） | 夏 | 夏章内出示 | 夏说出引流协议全貌与那张派单：「把你调走的单子，是我转发的。」黑幕线闭合 |
| 6 | 支线照片《天桥下拍星星的少年》 | 童 | 艾章获得并继承 | 直接命中「另一个我」锚点，等效私密钥词之一 |
| 7 | 碎片 6（最后的消息）+ 回响 4 达成 | 终章 | 终章开局背包含碎片 6，且苏晚章完整听完消息 | 「和解」结局解锁条件（见 7.4） |

## 7. 终章脚本骨架

### 7.1 切换时机与节奏总表

| 拍号 | 演出 | 玩家认知变化 | 系统 / UI 表现 |
| --- | --- | --- | --- |
| 0 | 苏晚章结束（无论当夜结局），照常回滚——进度条卡在 99% | 「循环坏了？」 | 回滚音效劣化、画面撕裂一帧 |
| 1 | **质子视角切换**：镜头垂直拉高，第一人称抽离为俯视第三人称。天台上只剩一个人——林默，正走向护栏 | 「我劝的是主角」 | 摄像机切固定俯视位；雨声抽空；BGM 静默 |
| 2 | 林默点烟，抬头看向镜头：「我知道你是什么。别装了。」 | 「我不是人」 | 输入框样式突变；玩家名称显示为 `RETENTION_AGENT.ai`；打字机效果变为数据流 |
| 3 | 碎片自检：背包界面自动展开，六枚碎片重排为「写入日志」，末行：写入者·林默，写入日 = 坠落之夜 + 3 个月 | 「整夜都是记忆循环，AI 是他亲手写入的」 | 档案界面变成芯片目录；历代归档摘要（无数次失败的尝试）一闪而过 |
| 4 | 林默转身面对镜头，站上护栏。**BGM 起：Im Sog der Feuer des Schicksals**（基线定曲，在此拍进入） | 「最终十句开始」 | 烟形句数条点燃：10 |
| 5 | 最终十句（见 7.3） | —— | 终章特例数值（见 7.3） |
| 6 | 收束：「接受」或「和解」（见 7.4） | —— | —— |

拍板：反转按「三拍递进」揭晓（视角→身份→写入真相），每拍只翻一张牌，避免一次性信息倾泻；拍 2 与拍 3 之间允许玩家自由查看档案，把「自己翻到真相」的主动权留给玩家。

### 7.2 反转的语义反置

全世界的逻辑在此反过来：这个世界里，公司用 AI 控制、挽留人类；而最终的十句，是 AI 选择去拯救它所寄宿的人。且这个 AI 的话术种子来自苏晚——终章里「你」每一句像样的话，都是她教的。

### 7.3 最终十句：陪伴与真实，而非说服

林默记得所有周目、所有套路，说服彻底失效。终章判定特例（意图定稿在此，数值与判定器实现见 [02 册](02_gameplay_systems.md) / [04 册](04_prompt_architecture.md)）：

| 常规规则 | 终章变化 | 理由 |
| --- | --- | --- |
| 好感事件 +1 句 | 取消——模板安慰、话术、说教一律无效 | 他写过这些话术 |
| 碎片命中 +2 句 | 碎片出示改为「共同回忆」必看演出，不加句 | 碎片在此是告别仪式，不是资源 |
| 延长手段 | 仅两类输入延长：**引用玩家自己在前几章真实说过的话/做过的选择**；**承认无能为力的真话**（如「我留不住你，但我想陪你到天亮」） | 主题落点：陪伴与真实 |

十句的主题弧（供 [04 册](04_prompt_architecture.md) 写终章提示词）：前 3 句拆穿与对峙 → 中 4 句共同回忆（六章碎片逐一回放）→ 后 3 句「不劝，先陪」（苏晚的原则由 AI 说出口）。

### 7.4 两种收束

| 结局 | 条件 | 演出 |
| --- | --- | --- |
| 接受（标准真结局） | 集齐主线 6 碎片进入终章，并在最终十句达成判定门槛 | 林默走下护栏。天亮——两年来第一次天亮。芯片提示「回滚功能已关闭」；AI 随之归档休眠。他把打火机放回护栏上，留给下一个需要多一句话的人，下楼 |
| 和解（隐藏结局） | 「接受」条件 + 回响 7：终章背包含碎片 6，且苏晚章完整听完最后的消息，且最终十句中至少一次向林默转述苏晚的原话 | 林默两年来第一次点开那条语音，听完，回复了它。他在天台等到日出。他没有关闭 AI：「陪我下楼吧。」彩蛋：现实层的艾（真实的她）清晨上天台晨拍，看见了他——层 A 与层 B 在镜头里闭合。此彩蛋与 v1 后日谈聊天资产的复用方案见 [02 册](02_gameplay_systems.md) |

失败分支（十句烧尽未达门槛）：不给死亡 CG——画面回滚到第 0 夜开场，周目号 +1，档案新增一条有损摘要。**终章唯一的失败是重新开始**（拍板：主角之死不可作为可达成结局，内容安全红线，详见 [00 册](00_project_charter.md)）。
