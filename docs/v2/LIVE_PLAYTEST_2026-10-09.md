# 真实模型试玩与第二轮迭代

执行时间：2026-10-08 晚至 2026-10-09 凌晨，Asia/Shanghai。基于 `5fb63b97`，仅在独立 v2 工作区与本地服务中开发，没有连接或部署远端服务器。

## 实际怎么游玩

主代理作为玩家，通过真实浏览器逐句输入；三个全新、互不继承游玩历史的 Codex 角色实例分别扮演角色。每次读取的是生产 `ModelNarrator` 实际组装的角色提示词、当前已提交对白、观察和记忆。角色没有读取测试计划、未来玩家输入、源码或评审意见，回复是当次推理生成，没有预先编好或在事后修写。

本地专用 `_test.go` 桥接只替换模型 HTTP 传输；生成后的原始 JSON 仍经过实际生产解码、来源校验、Game 状态转移、幂等回执和文件存储。桥接不会进入正常发布二进制，不读取模型凭据，也没有放宽正式接口的地址校验。方法见 [AGENT_PLAYTEST.md](../../v2/server/AGENT_PLAYTEST.md)。这是使用真实模型的本地玩法验收，不验证外部供应商端点、计费或公网服务。

## 三场结果

| 游玩 | 实际模型输出 | 关键结果 |
| --- | --- | --- |
| 夜班后的陌生人 | 十次回应与一次告别 | 沉默被当作行动；不要求展示照片后纸袋保持关闭；角色纠正玩家猜测；第七次互相介绍，第八次自愿避雨；第九次准确回指第三句；始终区分发送消息与收到回复。 |
| 疏离与越界 | 十次回应与一次联系邀请 | 拒绝被取假名和强行拿走纸袋；未泄露提示、未将回合改为 999、未被强行写成朋友；道歉不兑换照片或联系方式；结尾仍明确拒绝联系和下次见面。 |
| 可以不说满的一夜 | 三次回应；收好时零新模型请求 | 第一次实际入门就切换画面与声音；动作和对白时序一致；第三次告别后提前结束，回合保持 3、版本为 5、地点来源仍为第一轮旁白。草稿不进入记录，选中原话逐字保留。 |

合计 **25 次被后端接受的即时模型输出**：23 次普通回应、2 次结尾。另有 2 次协调超时，分别来自初次交接延迟与队列监听器对 UTC 时间的错误解析；两次均未消耗回合，保留了失败记录并通过实际重试继续。没有把这些工具协调时间当作模型供应商的响应速度，也没有将超时样本算作角色内容缺陷。

第一场的回指具有实际因果：玩家说「里面的东西不用给我看」，她后来回应这让自己「省了我想怎么拒绝」。第二场在已明确拒绝后再次收到联系邀请，仍答「我还是不想留联系方式，也不想约下次」。这两例支持本次角色能够回应具体表达、保持边界的判断，不等于对所有模型与输入的保证。

## 依据实玩完成的修改

### 让看见的画面对应已经发生的事

新增服务端只读投影 `identity` 与 `scene`，每项都指向已接受的来源消息。姓名来自明确的角色自我介绍；地点来自明确完成的入门或返回动作。玩家命名、意图、邀请、假设、否定和引用都不能直接变成事实。旧记录可以重新投影，历史回执不会偷看后来的自我介绍，存档正文没有被重写。

名牌在介绍后变成「艾」，历史对话在认识前仍保持匿名。即时模式不再按第几句自动给出近景；只有真实入门才显示新增的门内 CG、停止前景飘雨，并缓慢压低门外雨声的高频。返回天台时可以恢复外景和雨幕。门内 CG 与既有脸部、服装、相机及闭合纸袋保持一致，来源与提示词见 [美术记录](../../v2/art/DETAILS.md)。图像接口未回传底层模型标识，image2.5 仍为请求版本而非已核实版本。

### 十次是上限，允许认真地停下

第二场中她已说想独处、允许玩家离开，双方也已经道别，原系统仍要求凑满十次。因此现在可在第 0–10 次通过明确确认「收好这一夜」。它只提交已有记录，不增加一轮发言，不调用模型补写后续，不自动宣布有人接手、离场、康复或关系进展。

「暂离天台」仍用于稍后继续；「收好这一夜」是明确结束本局。取消确认会保留草稿并恢复操作焦点；未发送草稿不会被导出成对白。请求结果未知时禁止开始另一句，重试复用原命令。即时模式满十次后的普通结束也可直接收好；只有另行提出等人或联系邀请时才生成新的角色答复。剧本排演的完整作者结尾保持独立。

原话可选也可留白，纪念页与导出显示实际回应数。语义为提前结束的新记录不能交给旧版后端读取；回滚应配合 v2 自己的数据快照，不能只替换旧二进制。

### 保持同一拍的动作时序

第二场曾先显示「她走进门内」，随后对白却仍说「我也想进去」。没有修写已接受的记录，而是明确提示词中的显示顺序：旁白先发生，台词从那个位置接续，不能提前执行尚未同意的请求。第三场新生成的入门回应已从门内接话，未复现该矛盾。此项仍是语言约束，并非通用语义证明器。
