# AIC 竞赛版《天台十句》项目概述

> 2026-10-29 · `AIC` 竞赛版。玩法事实以代码契约为准，AI × 心理健康沟通规范见[Prompt 文档](../engineering/prompts_and_settings.md)，叙事正典见[游戏设定集](game_setting_bible.md)。

## 一句话介绍

《天台十句》是一款把人工智能与心理健康沟通学习深度结合的短篇叙事游戏：面对困境中的大学生艾，玩家只有十句话，需要自己组织每一次回应；AI 负责自然对白、心理健康沟通提示、独立结局裁判和局后复盘，程序把这些判断落实为信任、情绪、姿态与安全转移反馈。

## AIC 赛道特化：让 AI 参与“如何回应”

作品不把心理健康当作背景标签，而是把它拆成可观察、可解释的交互行为：

- **角色层**用创伤知情原则保持安全、边界、选择权和主体性，允许沉默与拒答，不把痛苦写成恋爱或救世主叙事。
- **提示层**以心理急救（PFA）的“观察—倾听—连接”和动机式访谈（MI/OARS）生成下一步方向，提示玩家回应具体内容、验证感受、征得同意并协作现实支持。
- **裁判层**只依据玩家语言和艾的自然回应判断验证、反映式倾听、选择支持、协作行动以及说教、责备、强迫等行为；游戏信任度不是临床分数。
- **复盘层**输出可观察的沟通技能、遗漏点、保留选择权的下一步和现实安全边界，不给玩家或艾下诊断。

这使 AI 的价值落在“把自由语言转成心理健康沟通反馈”，而不只是生成更像人的对白。

## 创作命题：只有十句话，你会怎样开口？

我们想让玩家关注那些已经很难开口的人，并在相遇时认真思考如何具体回应。核心体验是斟酌：这句话回应了她刚才说的什么？是否急着替她下结论？是否留下了继续表达的空间？玩家输入的每句话都要付出一次机会，无法用无限输出代替倾听。

这一命题适合通过游戏表达，因为玩家必须亲自开口、看到回应、调整下一句。紧张、犹豫、观察和试探构成玩法，立意由操作和后果产生。游戏没有预设一套人人适用的十句答案。

## 具体的人与具体的互动

艾承受着学业压力、网络嘲讽、家人的期待和长期孤独。这些内容通过对话逐渐浮现，玩家面对的首先是一个疲惫、戒备的人。当她说“说了也没人听”，下一句能否接住她刚才的表达，便成为玩家自己的问题。

“手机里输入求助又删除”的镜头是答辩演示的虚构设想，用于呈现开口的困难；它属于演示镜头，不属于当前游戏开场。

## 从语言到规则的闭环

1. 玩家自由输入，本局最多十次有效发送，每次消耗一次机会。
2. 角色模型结合上下文生成艾的自然回复。
3. 独立 JSON 裁判结合本句、回复和状态，判断信任变化、压力、情绪、姿态和结局。
4. 前后端程序校验字段与门槛，结算状态；信任增加不返还机会，压力不额外扣机会。
5. 对白、角色画面、剩余机会和结局把后果反馈给玩家，影响下一次表达。
6. 局后复盘从玩家实际语言中提取沟通技能、遗漏点、下一步和安全边界；这些描述不是心理诊断。

创新的完整论证及实现位置见[AI 原生机制论证](../engineering/innovation_mechanism.md)。

## 当前版本与完成边界

- 大学生艾、固定十句上限、信任 0—15、初始提示 3 次。
- 两个结局：安全离开 / 拒绝离开。安全离开须本轮结算信任达到 15，且 AI 判定叙事条件成立；满分不自动成功。
- 安全离开使用预制的“落泪—抹泪—一起进入楼梯间”三段 CG，之后可进入后日谈；拒绝离开止于仍在天台的沉默。
- 保留本地三栏位存档、成就、心理健康沟通提示及带技能标注的结局复盘；主线为角色与裁判两次顺序模型调用。
- 打字机是本地显示效果；未实现网络流式、实时生图、多模态上传、电话、碎片与循环系统。

十句限制单局交互规模；双调用为自然对白和结构化裁判提供独立契约。固定场景、短对白、结构化裁判和程序守门共同约束交互节奏。

## 希望玩家带走什么

游戏希望留下的是一种具体的停顿：遇到难以开口的人，先留意对方说了什么，再决定自己说什么。认真回应前文、询问对方此刻需要什么、商量眼前可以一起做的小事，构成可练习的沟通方向。

“只有十句话”是游戏规则，现实支持没有十句期限。结局与分数不代表现实处置能力。艾走进楼梯间也只是故事的一步；后日谈让一次相遇继续展开。作品的表达落在玩家如何开口，以及游戏结束后会怎样对待身边欲言又止的人。
